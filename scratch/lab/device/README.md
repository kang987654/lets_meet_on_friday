# device/ — 실기기·에뮬레이터 확인 도우미

`docs/checklists/device_gate.md` 의 확인 항목을 adb 로 돌리는 스크립트. 파이썬은 실험실과 같은 conda 환경(`friday`)을 절대 경로로 부른다(AGENTS §2-⑤).

| 파일 | 하는 일 |
|---|---|
| `adbtool.py` | 공통부 — 기기 지정, 타임아웃·재시도, "앞 화면이 우리 앱일 때만" 검사, 화면 노드 읽기 |
| `turn.py` | 채팅 한 턴 — 보내기 · 승인 시트 처리(approve / reject / leave) · 답이 끝나면 맨 아래 줄 출력 |
| `ui.py` | 화면 읽기·누르기·뒤로 |
| `frames.py` | 시작 화면 → 채팅 전환의 느린 프레임을 단계별로 |

**기기 지정**: `--serial=<id>` 또는 환경 변수 `KOSMOS_ADB_SERIAL`. 휴대폰과 에뮬레이터를 함께 꽂았다면 반드시 지정한다(에뮬레이터는 보통 `emulator-5554`).

**규칙(사용자 결정)**
- 앞 화면이 `com.kosmos.app` 일 때만 화면을 읽고 누른다 — 다른 앱은 읽지 않는다(스크립트가 검사하고 멈춘다).
- 휴대폰 캡처는 분석 뒤 PC 에서 지운다. 화면 덤프는 기기에서도 바로 지운다.
- 시스템 설정은 바꾸지 않는다. 앱 안 설정(테마 등)을 바꿨으면 끝에 되돌린다.
- 승인 시트는 1분이 지나면 저절로 취소된다 — `turn.py` 는 시트를 보면 바로 누르고, adb 가 응답하지 않으면 기다리지 않고 끝난다(종료 코드 3).
