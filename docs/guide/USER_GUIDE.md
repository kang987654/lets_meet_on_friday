# KOSMOS 사용 안내
> 기준: 앱 0.39.0 · 2026-10-29. 영어판과 함께 고칩니다 — 내용이 다르면 이 한국어판이 기준입니다.

KOSMOS 는 서버 없이 휴대폰 안에서만 동작하는 AI 비서입니다. 말로 부탁하면 일정·알림·메모를 만들고, 지난 대화와 메모를 찾아 답합니다.
일정·알림·메모를 저장할 때는 항상 확인을 받습니다.

## 1. 필요한 것
| 항목 | 내용 |
|---|---|
| 기기 | 안드로이드 8.0(API 26) 이상, 64비트(arm64). **RAM 12GB급 권장** — 실행 중 약 5GB 를 씁니다. 확인한 기기는 Galaxy S25 Ultra 하나입니다 |
| 저장 공간 | 모델 약 3.6GB + 여유 — 내려받기 전에 약 4GB 이상 비어 있어야 합니다 |
| 네트워크 | 모델을 처음 받을 때만(Wi-Fi). 그 뒤 대화는 인터넷 없이 됩니다 |
| 언어 | 화면·대화 모두 한국어입니다(영어는 계획 중) |

## 2. 설치
지금은 미리 만든 APK 를 배포하지 않습니다. 소스에서 빌드해 설치합니다.

```bash
git clone https://github.com/kang987654/lets_meet_on_friday.git
cd lets_meet_on_friday
./gradlew installDebug
```

Android Studio(JDK 17 이상)로 열어 실행해도 됩니다.

## 3. 처음 실행 — 모델 받기
- 첫 화면에서 **모델 내려받기**를 누르면 Wi-Fi 에서 약 3.6GB 를 받습니다. 중간에 끊겨도 이어받고, 앱을 닫아도 백그라운드에서 계속됩니다.
  나중에 **설정 › AI 모델**에서 다시 받을 수 있습니다.
- 직접 넣으려면 `gemma-4-E4B-it.litertlm` 파일을 `Android/data/com.kosmos.app/files/models/` 에 복사합니다.
- 모델을 깨우는 데 10초 정도 걸립니다(시작 화면). 다른 앱에 다녀오면 메모리를 비우려고 모델을 내리므로, 돌아올 때 다시 깨웁니다.

## 4. 권한
필요할 때 묻습니다. 거절해도 나머지 기능은 됩니다.

| 권한 | 쓰는 곳 |
|---|---|
| 마이크 | 음성으로 말하기 |
| 캘린더 | 일정을 기기 캘린더에 넣고, 기기 일정을 함께 보기 |
| 알림 · 알람 및 리마인더 | 정한 시각에 알림 울리기, 재부팅 뒤 알림 복원 |

## 5. 쓰는 법
**대화** — 하나의 대화가 계속 이어집니다("새 대화" 버튼이 없습니다). 30분 쉬면 앞 대화는 주제별 기억으로 정리됩니다.

| 이렇게 말하면 | 이렇게 됩니다 |
|---|---|
| "다음 주 월요일 10시에 팀 회의 잡아줘" | 일정 확인 시트 → **추가하기**를 누르면 앱과 기기 캘린더에 등록 |
| "30분 뒤에 물 마시라고 알려줘" | 알림 확인 시트 → 정한 시각에 알림 |
| "내 자전거 비밀번호 4821이야 기억해줘" | 메모 저장 확인 시트 |
| "내 사물함 번호는 214번이야" (저장 부탁 없이) | 저장하지 않고 "메모해 둘까요?"라고 묻습니다 → "응"이면 저장 확인 시트 |
| "자전거 비밀번호 뭐였지?" | 메모·지난 대화를 찾아 답하고, 근거(메모·지난 대화)를 카드로 붙입니다 |
| "오늘 일정 뭐 있어?" | 앱 일정과 기기 캘린더를 함께 봅니다 |

- **확인 시트**는 1분 안에 고르지 않으면 취소됩니다. 취소하면 저장하지 않았다고 짧게 답합니다.
- **음성**: 입력란의 마이크를 누르고 말합니다(최대 30초). 모델이 받아 적은 뒤 답합니다.
- **첨부**: 클립 아이콘으로 이미지나 문서를 붙여 물어볼 수 있습니다. 문서는 앞부분만 대화에 들어갑니다.
- **웹 검색**: 입력란의 지구본을 켠 동안만 위키백과를 찾아봅니다. 기본은 꺼져 있습니다.
- **답 읽어 주기**: 답 아래 스피커 아이콘.

**다른 화면** — 왼쪽 위 메뉴(☰)에서 엽니다.
- **지난 대화**: 주제별로 정리된 기억. 검색하고, 요약을 고치거나 지우고, 원래 대화 위치로 갈 수 있습니다.
- **일정**: 오늘·다가오는 일정, 월 캘린더(공휴일), 할 일.
- **문서**: PDF·엑셀·CSV·워드·한글 파일을 AI 없이 가볍게 엽니다(엑셀은 원본 서식 그대로). **채팅으로**를 누르면 그 문서에 대해 물을 수 있습니다.
- **프로필**: 비서가 참고하는 나에 대한 정보. 대화에서 뽑은 제안을 골라 저장합니다.
- **설정**: 테마·글꼴·채팅 글자 크기·시작 화면, 아침 브리핑 시각, **기억 정리**(주간 회고·겹치는 메모 합치기), 활동 기록, 데이터 초기화.
  백업 내보내기·가져오기는 메모 화면의 메뉴에 있습니다.
- **홈 위젯·빠른 설정 타일**: 오늘 일정과 할 일을 보고, 타일로 바로 음성 입력을 시작합니다.

## 6. 개인정보
- 대화·메모·일정·음성은 **기기 밖으로 나가지 않습니다.** 인터넷을 쓰는 것은 모델 내려받기와, 직접 켠 위키백과 검색뿐입니다.
- 비서가 실행한 일(일정 추가·메모 저장·검색 등)은 모두 **설정 › 활동 기록**에 남습니다.
- 저장 데이터는 안드로이드 앱 저장 공간(다른 앱이 읽을 수 없는 곳)에 있고, 따로 암호화하지 않습니다. 백업 파일은 직접 안전한 곳에 두세요.

## 7. 알아 두면 좋은 것
- **기억하는 대화가 짧습니다** — 최근 몇 턴만 직접 기억하고, 그 밖은 지난 대화·메모를 찾아 답합니다. 중요한 것은 "기억해줘"로 메모해 두세요.
- **틀릴 수 있습니다** — 작은 모델이라 가끔 잘못 이해합니다. 저장 전에는 항상 확인 시트가 뜨니 내용을 보고 고르세요.
- **기기가 뜨거우면**(배터리 약 43°C 이상) 기억 정리·브리핑 같은 뒤에서 하는 일을 미룹니다.
- **새로 읽는 턴은 느립니다** — 모델을 깨운 직후나 대화가 길어져 정리된 직후의 첫 답은 10초 이상 걸릴 수 있습니다.

## 8. 에뮬레이터에서 실행 (개발자용)
- x86_64 AVD 에 모델 파일을 위 3의 경로로 직접 넣습니다. 앱이 에뮬레이터를 알아보고 **CPU 로만** 모델을 돌립니다(GPU 경로는 에뮬레이터에 없는 OpenCL 을 찾다 답 생성에서 실패합니다).
- 답은 됩니다 — 툴 호출·승인 시트까지 확인했습니다. 다만 느립니다(짧은 답에 수십 초, 첫 실행은 CPU 캐시를 만드느라 몇 분 더). 기능 흐름 확인용이고, 속도·발열 판단은 실기기로 합니다.

## 9. 문제가 생기면
| 증상 | 해 볼 것 |
|---|---|
| 모델이 없다 / 불러오지 못했다 | 설정 › AI 모델에서 다시 내려받기 |
| 내려받기가 멈춤 | Wi-Fi 연결 확인 — 이동통신망에서는 받지 않습니다 |
| 알림이 안 울림 | 알림·"알람 및 리마인더" 권한 확인 |
| 일정이 기기 캘린더에 없음 | 캘린더 권한 확인(앱 안의 일정은 그대로 저장됩니다) |

문의·버그는 저장소 이슈로 남겨 주세요.
