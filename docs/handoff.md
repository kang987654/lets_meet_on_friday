## 3. 열려 있는 것 (할 일은 아님 — 다시 보이면 회차로)

- **토큰 여유 약 20토큰** — 예약 `Constants.PREFILL_OVERHEAD_TOKENS` 대 `TokenBudgetInvariantTest.MEASURED_OVERHEAD`. 0.42.9 에서 18토큰 지시 한 줄이 회귀 세트 clock·inject 묶음을 흔들어 접었다. 프롬프트를 늘리는 일은 전부 실측부터.
- **기억 → 알림**(0.42.9 접음) — 시스템 지시를 손볼 때 회귀 세트 `remind_mem` 묶음으로 다시 잰다. 그 묶음은 기준값(`baseline.json`)에 **아직 저장 안 함**(지금 0/4 가 예상값, 저장은 사용자 확인 뒤).
- **채팅 "할 일 추가·조회" 툴 없음** — 채팅은 날짜 없는 할 일을 못 보고 아침 브리핑만 본다. 실사용 중 필요하면 한 회차로(모델 입력 증가 → 실측 선행).
- **GPU 임베딩 + 채팅 모델 공존 시 채팅 출력 깨짐**의 근본 원인 — 0.42.8 에서 임베딩 기본값을 CPU 로 바꿔 피함.
- 시각을 답한 뒤 끝 시각만 다시 묻는 흔들림(0.42.5 기록).
- README: ADR 을 39개로 적음(실제 40번까지), "앞으로의 순서"가 끝난 0.39.x 로드맵을 가리킴.

## 4. 저장소 밖에만 있던 작업 메모 (AGENTS.md 에 없는 것)

- **에뮬레이터 `my_phone`** — 모델 파일이 들어 있고 CPU 로 답 생성까지 된다. `adb -s emulator-5554`. 기능 흐름·재현·진단은 여기서.
- **휴대폰은 실사용 기기** — GPU·성능·삼성 고유 동작·짧은 최종 확인에만 쓴다. 쓰기 전에 무엇을·왜·몇 분인지 먼저 묻는다. 확인 중 승인 시트는 거절(실제 일정·알림을 만들지 않음). 끝나면 `adb kill-server`.
- **adb 위치** `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`, 휴대폰 시리얼은 환경 변수 `KOSMOS_ADB_SERIAL` 로 넘긴다. 채팅 한 턴 보내기·화면 읽기 도구는 `scratch/lab/device/turn.py`·`ui.py`.
- **실험실 파이썬** — 셸 heredoc 으로 정규식을 쓰면 `\b` 가 깨진다(파일 편집 도구로). 리다이렉트한 출력에 한글이 있으면 `sys.stdout.reconfigure(encoding="utf-8")`.
- **게이트는 10분을 넘길 수 있다** — 시간 제한에 걸려도 백그라운드에서 끝까지 돈다.
- **서랍(드로어) 뜻 검색 허용 폭 0.04** — 민법 문서 하나로만 확인한 값. 검색이 불편하다는 말이 나오면 이 값부터.
- **화면 엿보기는 위협 모델이 아님**(사용자 결정) — 화면에서 민감 값 가리기를 제안하지 않는다.
- **"QA 중 임의 수정 금지" 조항은 폐기됨** — 규칙 감사 때 유실로 보고하거나 복원을 제안하지 않는다.
- **사용자의 목표는 앱 + 포트폴리오** — 면접에서 설명·방어할 프로젝트다. 구현은 AI 에 맡기되, 갈리는 지점은 사용자 관점의 말로 묻는다(내부 약어 풀어서).
- **"실사용 전에 정리할까요?"라고 묻지 않는다** — 시험 데이터는 사용자가 실사용 시작 때 직접 지운다.
