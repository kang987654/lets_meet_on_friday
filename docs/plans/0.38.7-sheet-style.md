# 0.38.7 — 엑셀 셀 서식과 넘긴 것

## 목표
문서 뷰어 표에 원본 엑셀의 셀 서식(배경·글자색·굵기·정렬)을 보여 주고, 0.38.6 실기기 확인·impeccable 재점검에서 넘긴 것을 정리한다.
모델에 들어가는 문서 글자(`DocumentText`)는 서식 없이 글자만 그대로다.

## 정한 것 (2026-10-26 사용자)
1. **서식 범위 = 배경·글자색·굵기·정렬** — 테두리·글꼴 종류·글자 크기·조건부 서식은 뺀다.
2. **다크 모드는 원본 색을 어둡게 바꿔 유지** — 배경은 색조를 살리고 밝기를 낮춘다, 대비가 부족한 글자색은 테마 글자색으로.
3. **함께 다룰 것**: 대화 속 답·근거 카드(실기기 T7), 은하 전환 가볍게, 활동 기록 툴 결과 문구, 메모 오호출·P3.
4. **활동 기록 툴 결과 문구는 화면에서만 바꿔 보인다** — 모델이 받는 문구는 그대로(실측·예산 영향 없음), "원문 보기"는 원문 그대로.

## 조사에서 확인한 사실 (2026-10-26)
- 표 숫자 천 단위 쉼표는 이미 된다 — 엑셀 숫자 서식(`#,##0` 등)을 `XlsxNumberFormat` 이 반영. 쉼표가 없는 건 서식 없는 csv 뿐이라 0.38.6 넘김 목록에서 뺀다.
- `XlsxReader.StylesHandler` 는 숫자 서식만 읽는다(`numFmt`, `cellXfs/xf@numFmtId`). 글꼴·채움·정렬·테마 색은 읽지 않고, `SheetCell` 은 글자만.
- 실기기 T7: "회의실 어디라고 했지?"에 "찾지 못했어요" + 앞 문장 인용, 관계없는 지난 대화("사물함 비밀번호…")가 근거 카드로 붙음.
- 실기기 T3: 은하가 열리는 1.2초 내내 프레임 26~53ms(가림막 오프스크린 합성 + 채팅 확대).
- 활동 기록 요약 줄에 보이는 툴 결과: 합니다체 7(`AddScheduleToolExecutor` "일정이 성공적으로 추가되었습니다.", `BaseAgent` 인자 오류·차단 문구 등), "리마인더 등록" 2(`AddReminderToolExecutor`).

## 마일스톤 (각각: 구현/측정 → 사용자 확인 → 게이트 → 커밋)
- **M0 셀 서식 읽기** — styles.xml 의 fonts(b·color), fills(patternFill fgColor), cellXfs/xf(fontId·fillId·applyAlignment·alignment@horizontal),
  테마 색(`xl/theme/theme1.xml` + tint), indexed 색표. 서식은 셀마다 복사하지 않고 `Sheet.styles` 표 + 셀의 번호(`SheetCell.style`, 기본값으로 csv·기존 생성부 호환).
  단위 테스트: 테마 색 + tint, indexed, 직접 RGB, 굵기, 정렬, 서식 없는 셀.
- **M1 셀 서식 그리기** — SheetView 에 배경·글자색·굵기·정렬. 다크 변환은 순수 함수 + 대비 테스트. 고른 행 배경이 서식 배경보다 우선, 숫자 기본 오른쪽 정렬은 서식 정렬이 없을 때만.
  DESIGN "하드코딩 색 0" 지표에 "원본 문서 색" 예외. 카탈로그에 서식 있는 표 장면(라이트·다크), 사용자 전후 확인.
  - **M0·M1 결과(2026-10-26)**: 계획대로. 갈린 점: 대비가 모자란 원본 글자색은 테마 글자색 대신 밝기만 옮김(빨간 음수가 다크에서 흰색이 됐다), 병합 칸은 원본 정렬을 따르지 않음.
- **M2 대화 속 답·근거 카드** — 실험실에서 T7 재현(무관한 지난 대화가 함께 걸린 결과) → 근거 카드·회수 칩에 약한 지난 대화를 올리지 않는 점수 하한, 결과 문구 실측. 회상 호출·스모크 회귀.
  - **M2 결과(2026-10-26)**: 화면 근거 하한 0.75, 결과 있을 때 안내 한 줄, 메모 거절 문장 "메모에는 남기지 않았어요.". 갈린 점: 실기기 실패의 진짜 조건은 앞 턴의 거절 문장(실험실은 그것 없이 6/6).
- **M3 은하 전환 가볍게** — 오프스크린 층 + DstOut 가림막을 원 자르기 + 테두리 빛 덧칠로. 휴대폰 framestats(온도를 맞춰 같은 조건 비교).
  - **M3 결과(2026-10-26)**: 원 자르기 + 바탕색 덧칠. 측정은 M6 휴대폰 확인으로 미룸(사용자 결정).
- **M4 활동 기록 툴 결과 문구** — `AuditLabels` 표시에서만 해요체·"알림"으로(결정 4).

  P3: 드로어 검색칸 모양, 오늘 화면 제목 반복, 말줄임표 "..." → "…", 위젯 12·11sp.
