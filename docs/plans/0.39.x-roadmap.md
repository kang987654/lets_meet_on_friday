## 원칙 (AGENTS·04_MODEL_EVIDENCE 그대로)
- **실측 선행**: 회차는 M0 실측(코드 수정 0, 측정용 임시 로그는 커밋 안 함)으로 시작하고 결과로 "진행 / 닫기"를 정한다. 수치에는 근거 등급, 없으면 "모른다".
- 계획서는 구현 전에 커밋, 마일스톤마다 `./gradlew test lintDebug assembleDebug`, 기존 단언 수정은 사용자 확인 후.
- 모델 입력이 바뀌면 실험실 실측 → `MEASURED_OVERHEAD` 갱신(지금 여유 35) → 부족하면 대화 기록 몫이 줄어드는 대가를 적고 승인 후 예약 증액.
- 성능 수치는 디버그 빌드로 판단하지 않는다 — 최적화 빌드로 잠깐 재고 되돌린다(0.38.9 M5).
