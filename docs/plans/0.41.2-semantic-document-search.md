# 0.41.2 — 채팅에서 문서 찾기와 선택형 임베딩 (EmbeddingGemma 2)

## Context
0.41.0 은 보관함 등록·바이그램(FTS4) 색인·검색 엔진까지 만들었고 모델 입력은 건드리지 않았다. 이 회차는 **채팅에서 보관함을 찾아 근거와 함께 답하는 것**과,
바이그램이 못 잡는 "바꿔 말한 질문"을 메우는 **임베딩(뜻 검색)** 을 붙인다.

실측 근거(0.41.0 M0 후속, PC, 공개 법령 30문항):
- 바이그램만: 바꿔 말한 질문 @1 **1/10** — "몰래 가져가면" ↔ "절도" 를 못 잇는다.
- 모델이 검색어를 바꿔 쓰면(exp75 "R" 설명): 바이그램 @1 5/10. 단 **그냥 물으면 툴 호출이 2~4/10** — 이것이 병목.
- EmbeddingGemma 2 740M(768차원): 질문 원문 dense @3 6/10, 모델 검색어 + dense 8/10, **dense + 0.1 × (sparse/최고점)** 이 가장 나음(같은 용어 9/10·바꿔 말함 8/10).
  RRF·sparse 비중 큰 결합은 dense 이득을 지웠다. 256차원은 한국어 손실(6→4) → 768.
- ADR-013(기억 검색이 벡터가 아닌 이유: 쓸 수 있던 임베더가 영어 전용)의 전제가 이 모델로 풀린다 — 이 회차는 문서만, 기억은 0.41.3.

## 결정 (사용자, 2026-11-04)
- **트리거 = 입력창의 작은 팝업에 토글 2개(웹 검색·문서 검색)**. 지금의 지구본 버튼(웹 검색 토글)을 팝업 버튼으로 바꾼다. 문서 검색을 켠 동안만 보관함을 찾는다.
  모델이 "찾을지" 판단하는 비중을 줄여 툴 호출률 병목을 피한다.
- **임베딩 모델 = EmbeddingGemma 2 740M**(`litert-community`, Apache 2.0). 텍스트만 쓰면 실행 메모리 약 191MB(블로그, Pixel 11 Pro — 인코더는 필요할 때만 올림),
  받기 485MB. 270M 비교는 하지 않는다. 사진 보관함 등 멀티모달은 이 회차 범위 밖(같은 모델로 나중에 가능).
- **임베딩은 선택 설치**. 기본은 지금의 바이그램, 설정에서 모델을 받으면 그때부터 결합 검색(dense + 0.1 × sparse)을 우선한다.
  - 받은 직후 기존 조각의 벡터를 만든다(아래 Q4 — 버튼) — **전부 끝날 때까지는 바이그램, 끝나는 순간 결합으로 전환**(일부만 벡터가 있으면 순위가 왜곡된다).
  - 모델을 지우면 즉시 바이그램으로, 저장된 벡터도 지운다. 벡터에는 만든 모델 id 를 함께 저장해 모델이 바뀌면 자동 폐기.
- **바이그램은 없애지 않는다** — 결합 점수의 sparse 항, 조문 번호 구조 조회, 모델이 없을 때의 경로로 남는다.
- **스캔(이미지) 문서는 OCR 없이 지금처럼 "글자를 읽을 수 없는 문서"로 실패 처리** — EmbeddingGemma 의 이미지 입력은 70/140 토큰 요지라 글자 검색이 안 된다.
- 문서 첨부 배치 정리(0.40.8 에서 미룬 질문 중복)·뷰어 "보관함에 추가" 메뉴는 이 회차에 넣지 않는다.

## 계획 단계에서 정할 것 (사용자 확인)
- **Q1. 문서 검색이 켜졌을 때 찾는 방식** — M0 실측 후 확정.
  - **A. 앱 선검색**: 매 턴 사용자 문장 원문으로 앱이 먼저 찾아 결과 묶음을 이번 입력에 붙인다. 툴 호출 없음(지연·호출률 문제 없음).
    대신 검색어가 원문 그대로라 모델이 없으면 바꿔 말한 질문에 약하고(@1 1/10), "고마워" 같은 턴에도 결과가 붙는다(관련도 하한으로 거른다).
  - **B. 켜졌을 때만 `search_documents` 선언 + 강한 트리거 한 줄**: 모델이 용어로 바꾼 검색어로 찾는다(바이그램 @1 5/10, 결합 @3 8/10).
    꺼져 있으면 선언하지 않아 평소 오버헤드 0. 대신 툴 왕복 한 번의 지연과, 켜 놓아도 안 부를 가능성이 남는다(exp75 "문서에서" 판은 10/10).
  - 제 예상은 **B**(검색어 재작성이 품질 차이가 크다). M0 에서 A·B 를 같은 세트로 비교해 수치로 보여 드린 뒤 정한다.
- **Q2. 문서 검색 토글 저장 — 확정(사용자 2026-11-04)**: 웹 검색처럼 앱을 다시 켜도 유지(DataStore, 기본 꺼짐). 보관함이 비면 토글을 비활성 + "보관함이 비어 있어요".
- **Q3. 임베딩 실행 장치** — M2 끝 기기 실측으로 결정: NPU(휴대폰이 SM8750 이고 AAR 0.19.0 에서 돌 때, 전용 544MB 파일) / GPU / CPU.
  NPU 판을 쓰면 기기 칩에 따라 받는 파일이 갈린다(두 파일을 다 받지 않는다).
- **Q4. 벡터를 언제 만드나 — 확정(사용자 2026-11-04)**: 자동 백그라운드가 아니라 **사용자가 시작하는 작업**("기억 정리" 전례 — `MemoryCleanupRunner`).
  - 대량(모델을 받은 직후·모델이 바뀐 뒤): 보관함 구역의 **"뜻 검색 준비" 버튼** — 진행률·취소·다시 누르면 이어서.
  - 새 문서 등록: 등록이 곧 사용자가 시작한 작업이므로 **색인이 끝나면 그 문서만 이어서 임베딩**(모델이 있을 때).
  - 준비 안 된 문서가 있으면 보관함 구역에 "뜻 검색 준비 안 된 문서 n개 · 준비하기" — 그동안 검색은 바이그램(전환 규칙 그대로).
  - 임베더(약 191MB)에도 "백그라운드에서 모델 로드 금지"(AGENTS §2-⑥) 적용 — 앱이 화면에 있을 때만 돌고 `onStop`(엔진 해제)에서 취소, `onTrimMemory` 에서 내린다.
  - [WHY] 채팅 중 모르는 사이 GPU 를 쓰지 않는다(0.40.7 경합·발열). 새 문서까지 수동이면 문서 하나 때문에 보관함 전체가 바이그램으로 돌아가는 일이 생긴다.

  디버그 빌드 전용 측정 진입점(로그)으로 하고 제품 코드에 측정 화면은 두지 않는다.

### M3 — 선택 설치와 벡터 생성 (`:app`)
- 설정 > 모델 관리에 **"임베딩 모델(선택)"** 항목: 크기·효과 설명, 받기(기존 WorkManager 다운로드 경로를 대상 하나 더 받도록 일반화 — 유니크 작업 이름·파일명·URL
  상수 분리, 이어받기·Wi-Fi 대기 동작 동일), 지우기(파일 + 벡터), 상태.
- `LibraryEmbedder`(@Singleton, `MemoryCleanupRunner` 의 상태 모양 — Idle/Running(done,total)/Done/Cancelled): `prepareAll()`(버튼 — 벡터 없는 조각 전부),
  `prepare(documentId)`(`LibraryIndexer` 가 색인 성공 직후 부름 — 모델이 없으면 아무것도 안 함). 묶음 단위로 임베딩·저장해 끊겨도 다음에 이어서(멱등).
  채팅 턴 중에는 멈춤, 앱 `onStop` 에서 취소. 보관함 구역: 진행률 "뜻 검색 준비 중 n/m", 준비 안 된 문서 수와 "준비하기" 버튼.
- 테스트: 가짜 임베더로 버튼 일괄 생성·중단 재개·취소·턴 중 멈춤, 등록 직후 그 문서만 생성(모델 없으면 생략), 준비 안 된 문서 수 표시, 모델 삭제 시 벡터 삭제와
  바이그램 복귀, 다운로드 일반화가 Gemma 다운로드 동작을 바꾸지 않음.

### M4 — 채팅 연결 (`:app`, 프롬프트 표면 — 실측 선행)
- 입력창: 지구본 버튼 → **검색 팝업 버튼**(켜진 토글이 있으면 강조 색 + 상태 설명). 팝업에 웹 검색·문서 검색 스위치. 웹 검색 의미(위키 툴 게이트)는 그대로.
  문서 검색 토글 저장(Q2), 보관함이 비면 비활성.
- Q1 확정안 구현 — B 면 `search_documents` 툴(ToolNames → 실행기 → `AgentModule` → `KosmosToolDeclarations` → `KosmosAgent` 활성 목록(토글 켜짐 + 보관함 있음)
  → 트리거 줄), 검색어 설명은 exp75 "R"(문서에 쓰였을 용어로). 결과는 `ToolResultJson`. 감사 기록 라벨·아이콘.
- **출처 카드**: 답 아래에 찾은 문서명·조문/쪽 카드. 누르면 뷰어를 그 위치로 연다 — `DocumentViewerActivity.intent` 에 위치 인자(PDF 쪽, 흐름 문서는 조각 머리말로
  찾아 스크롤) 추가. 원본 권한이 없으면 "원본을 찾을 수 없음"(0.41.0 D2).
- 실측: 오버헤드 재측정·`MEASURED_OVERHEAD` 갱신, 회귀 세트 재실행(토글 꺼짐 상태에서 기존 결과가 그대로인지가 핵심), 기능 스모크(에뮬레이터 CPU).
- 테스트: 토글 꺼짐 → 선언·결과 없음(기존 픽스처 불변), 켜짐 → 선언/결과 묶음, 보관함 비면 미선언, 출처 카드 누르기 → 위치 인자, 화면 카탈로그.
