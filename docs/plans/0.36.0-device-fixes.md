## 고정 제약
- **채팅 시스템 지시 바이트 불변**(ADR-010 재프리필 방지). 시각·긍정 답 보강은 **턴 리마인더**(사용자 턴)에만 넣는다.
- 프롬프트 표면(턴 리마인더·툴 결과 문구·추출/브리핑 oneShot 지시)을 바꾸는 항목은 **M0 실측 후 원문 그대로** 적용(§2-⑤). `MEASURED_OVERHEAD`
  는 실측으로 갱신하고 CHANGELOG 에 수치를 남긴다. 추출 지시를 바꾸면 `ExtractFactsUseCase` [WHY] 대로 exp36 계열을 다시 잰다.
- **실험 스크립트는 합성 데이터로** 새로 짠다 — exp48(실대화 재생)은 세션 임시 폴더에만 있고 커밋하지 않는다. 합성판 exp49 가 같은 상황을 재현한다.
- E2E 계약(`"Attach"`/`"Send"`/`"Document Attached"`) 불변, `ChatScreen` 신규 파라미터는 기본값.
- 기존 테스트 단언 수정은 **대상 목록을 먼저 보이고 확인 후**(§2-②). 이 회차에서 예상되는 대상은 아래 M1 에 적었다.

## 승인 결정 (2026-10-13)
- **D0 버전**: 이 수정 회차가 **0.36.0**, 대기 중인 hwp 회차는 **0.37.0** 으로 이름을 바꾼다(`0.37.0-hwp.md`).
- **D1 자동 지식 저장 방식**: **(B) 자동 저장 유지 + 필터**. 지식을 제안 카드로 돌리는 안(A)은 사용자가 확인할 것이 늘어나 기각(사용자 결정).
  사용자가 직접 저장하는 경로(`add_memory` 승인 카드)는 그대로다 — 필터는 **자동 추출에만** 적용된다.
- **D2 자동 저장 필터**(결정적 코드, 저장 직전): ① 같은 에피소드 구간에 `APPROVAL_REJECTED AddMemory` 가 있고 내용이 겹치면(바이그램 containment ≥ 0.3,
  `BigramMatcher.containment`) 저장하지 않는다 — 거절 우회(⑤) ② 기존 메모와 **같은 대상·다른 숫자**(0.30.0 `MemoryMergeGuard` 의 숫자 집합 비교 재사용)면
  저장하지 않는다 — 확인 안 된 값이 확인된 값을 덮지 못하게(⑥, 예: 수동 "자전거 비밀번호는 134" 가 있으면 자동 "자전거 비밀번호: 4321" 건너뜀)
  ③ 리마인더 요청 문형(알림·알려줘·설정 필요 + 시각)은 저장하지 않는다 — 처리가 끝난 일회성 요청(②). "매일 아침 7시 운동"처럼 반복 습관은 저장
  ④ 태그는 에피소드 태그 대신 **노트 내용과 겹치는 태그만** 남기고, 없으면 빈 태그(⑦b).
- **D3 기억 검색 순위**: 바이그램 동점이면 **수동 메모 > 자동 메모 > 에피소드 요약** 순, 그다음 최신순. 그리고 절단 전에 메모(지식) 몫을 먼저 담고
  에피소드 요약은 남은 예산에 담는다(요약 1건이 수십 토큰이라 메모를 밀어내지 않게). 결과 문구(모델 입력)는 순서만 바뀌고 형식은 그대로.
- **D4 알림 권한 요청 시점**: ① 리마인더 **승인 직후** 권한이 없으면 시스템 요청(캘린더 권한 런처와 같은 자리 — `ChatScreen`) ② 설정 "매일 아침 브리핑
  받기"를 켤 때 ③ 거부 상태면 리마인더 승인 응답 뒤 스낵바 "알림 권한이 꺼져 있어 알림이 화면에 뜨지 않아요 — [설정]". 정확 알람은 기존 설정 안내 행
  유지 + 승인 카드에 "알림이 최대 10분 늦을 수 있어요" 한 줄(권한 없을 때만). 앱 첫 실행 온보딩 요청은 하지 않는다(맥락 없는 요청은 거부율이 높다).
- **D5 턴 리마인더 보강**(M0 게이트 통과 시): `[Now] HH:mm` 과 긍정 답 문장. 시스템 지시는 그대로라 KV 재사용 유지 — 지난 턴의 리마인더에 남은
  옛 시각은 히스토리일 뿐이다. `PromptAssembler.buildDateBlock` 의 "한 시간 뒤 같은 시계 의존 발화는 다루지 못한다" [WHY] 와 ADR-010 에 보강 사실을 적는다.
- **D6 첨부 말풍선(ⓐ)**: 저장 형식은 그대로 두고(모델 입력·히스토리 계약) **표시만** 바꾼다 — `[Attached Document]` 로 시작하는 USER 메시지는
  "📎 첨부 문서 · n자" 접힌 칩으로 그리고 탭하면 펼친다.

## M0 — 실측 (exp49, 합성 데이터, `scratch/lab/` 커밋)
`scratch/lab/exp49_device_fixes.py` — 시스템 지시·툴은 `fixtures/` 를 읽는다(손으로 베끼지 않음).
1. **턴 리마인더 조합**: 조건 A 현행 / N `[Now] HH:mm` / NC `[Now]` + 긍정 답 문장. exp48 에서 실측한 원문:
   - `[Now]`: 현행 리마인더 끝에 `" [Now] 14:49"` (9토큰)
   - 긍정 답: `" If the user is answering your previous question, carry out what you proposed."` (15토큰)
   - 측정: 상대 시각 8발화("1분 뒤·30분 뒤·한 시간 후·내일 9시·오후 5시·지난 시각" 등, 정답 = now 기준) · 긍정 답 6형("어·응·그래·ㅇㅇ·해줘·네") × 히스토리 2형
     (KV 경로·재생성 경로) · exp41 스모크 21건(툴 선택·무호출·날짜 끌림) · 무호출 기대 "응"(정보성 질문 뒤).
   - **게이트**: 상대 시각 ≥ 7/8, 스모크 21/21 무손상, 긍정 답 KV 경로 ≥ 5/6 이고 무호출 "응" 오호출 0. NC 가 N 보다 나쁘면 긍정 답 문장은 빼고 N 만.

## 실기기 게이트 (이 회차)
1. 모델 파일을 직접 넣은 기기에서 리마인더 승인 → 알림 권한 요청 → 허용 → 정시 알림 표시 / 거부 → 스낵바 안내
2. 메모 저장 거절 → 30분 뒤 같은 사실이 자동 저장되지 않음
3. "자전거 비밀번호 기억나?" → 수동 메모 값으로 답함(틀린 자동 노트를 지운 뒤) · 같은 대상 다른 숫자가 다시 자동 저장되지 않음
4. "1분 뒤 알려줘" → 승인 카드 시각이 지금 + 1분
5. 비서 제안 직후 "어" → 제안대로 실행
6. 다음 날 아침 브리핑에 오래된 대화를 "어제"로 부르지 않음
7. 라이트 모드 상태바 아이콘 보임(채팅·뷰어), 다크 모드 그대로
8. 이미지형 PDF 페이지 "글자 없음" 안내 · 첨부 말풍선 칩
