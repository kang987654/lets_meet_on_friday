## 결정 (사용자, 2026-11-05)
- **Q1 = (b) OkHttp 5.5.1 로 올림** — 처음엔 "4.12 에 알려진 취약점 없음"으로 동결을 추천했으나 변경 기록을 확인해 정정했다: 4.12 는 2023년 마지막 4.x 라
  5.x 의 보안 강화(5.4 HTTP/2 응답 헤더 256KiB 상한, 5.5 호스트 이름 검증의 IP 정규화 실패 거부, 5.5.1 유출 인증서 8개 차단 — 마지막은 Play 서비스 기기면 OS 가 받음)가 없다.
  API 변화(`Response.body` non-null, 시간 초과 `kotlin.time.Duration`)는 쓰는 두 곳(위키백과 검색·모델 내려받기)만 고친다. 옛 `mockwebserver` 는 계속 배포되므로 테스트 이전은 하지 않는다.
- **Q2 = (a) TFLite 3종 제거** — 2026-06-12 `6b75201` 에서 구글 gallery 예제의 의존성 세 줄(이름·버전 키 동일)을 옮겨 온 것으로, 그때도 지금도 부르는 코드가 없다.
- **Q3 = (a) Robolectric 4.17** — 깨지면 `VoiceChatIntegrationTest` 의 벽시계 대기(`System.currentTimeMillis` 3초 + `Thread.sleep`)를 가짜 시계를 돌리는 폴링으로(단언 불변, 고칠 곳을 먼저 보임).

## 결정할 것 (사용자 확인 — 위에서 답함)
- **Q1. OkHttp 5** — 쓰는 곳은 위키백과 검색과 모델 내려받기(이어받기)뿐.
  (a) **추천: 4.12 동결 유지** — 알려진 취약점이 없고, 5 는 `mockwebserver` 가 `mockwebserver3` 로 바뀌어 테스트 생성부를 고쳐야 한다. 필요가 생길 때 별도 회차.
  (b) 5.5.1 로 올림 — 내려받기 이어받기를 휴대폰에서 다시 확인해야 한다.
- **Q2. play-services-tflite 3종** — 6월 엔진 안정화 때 들어왔는데 지금 앱 코드에 TFLite 를 부르는 곳이 없다(채팅·임베딩은 LiteRT-LM 이 자체 GPU 경로).
  (a) **추천: 빼고 휴대폰에서 채팅 GPU·뜻 검색 GPU 를 확인** — 쓰지 않는 라이브러리는 APK 크기·공격 면만 늘린다. 휴대폰에서 GPU 가 안 뜨면 되돌린다.
  (b) 그대로 둔다(다음 회차로).
- **Q3. Robolectric 4.17** — (a) **추천: 올려 보고 `VoiceChatIntegrationTest` 가 깨지면 테스트의 대기 방식을 벽시계 대신 폴링(AGENTS §2-②)으로 고친다**(단언은 그대로 — 고칠 곳을 먼저 보여 드림). (b) 깨지면 다시 동결.
