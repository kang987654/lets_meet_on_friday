# 0.39.6 — 기억 검색 보강 (의미 검색 실측 · 결과 잡음)

## 목표
유의어·상위 개념 질문("내가 좋아하는 음료가 뭐지?" ↔ 메모 "커피보다 녹차를 선호함")을 지금 기억 검색(`SearchMemoryToolExecutor`)이 얼마나 놓치는지 재고, 가벼운 것부터 보강한다. 0.39.3 M4c 실기기에서 확인된 결과 잡음(`RecallConflict` 가 요약 전체의 무관한 숫자를 긁는 문제)도 함께 고친다.

## 미리 정한 결정
1. 0.39.5(음성 인식 비교)는 이번 0.39.x 에서 제외(닫기)하고 0.39.6 으로 바로 넘어간다(2026-11-01 사용자 결정).
2. 보강 순서: ① M0 질의 세트(JVM 결정적 테스트)로 기준 적중률 고정 ② M1 `RecallConflict` 결과 잡음 제거(질의·메모 대상 근처 숫자만) ③ M2 쓰기 시점 태그 보강(메모·에피소드 요약 태그에 상위 개념, 실험실 실측 선행) ④ M3 읽기 시점 질의 확장(+1~2초 비용 결정 — STOP).
3. 한국어 임베더(C3)는 이 회차에서 하지 않는다(부족이 기록되면 새 ADR 과 함께 별도 회차).

## 마일스톤 (각각: 게이트 → 커밋)
- **M0 질의 세트 (JVM, 결정적)** — 유의어·상위 개념·붙여쓰기·표현 변형 20쌍 이상을 메모리 안 저장소(`KnowledgeRepository`·`EpisodeRepository`)로 `SearchMemoryToolExecutor` 에 돌려,
  ① 본문만 있을 때(태그 없음) 적중률 ② 상위 개념 태그가 있을 때 적중률 ③ 태그 목록 2차 회수(폴백 안내에 정답 태그 노출) 포함 적중률을 측정하고 테스트(`SemanticRecallBenchmarkTest`)로 커밋해 이후 보강의 기준으로 삼는다.
- **M1 결과 잡음 (`RecallConflict`)** — 0.39.3 M4c 실기기 원문: `- (과거 대화) 2건에는 다른 값이 적혀 있습니다: 5, 214, 6043, 1122, 9087)` — 질문("자전거 비밀번호")과 무관한 사물함(214)·송장번호(6043 1122 9087)·층수(5)까지 긁혔다.
  원인: `RecallConflict.valuesIn` 이 요약 전체에서 날짜·시각 단위만 빼고 모든 숫자를 긁는다. 다중 주제 에피소드 요약이나 다른 숫자가 섞인 요약에서 무관한 숫자가 들어간다.
  고침: `RecallConflict` 가 요약 전체가 아니라 **질의/메모 대상 낱말이 있는 문장(또는 절)** 의 값 숫자만 보게 좁히고, 층·번지·개·명·회·층수 같은 일반 수량 단위도 값 숫자에서 뺀다.
  실험실(`exp70_recall_conflict.py`) + 회귀 세트(`newval`·`repeat`·`overlap` 우선, 전체 확인) + 단위 테스트(`RecallConflictTest`·`SearchMemoryToolExecutorTest` 추가, 기존 단언 불변).
- **M2 쓰기 시점 태그 보강** — ① 에피소드 요약(`SummarizeEpisodeUseCase.SYSTEM_INSTRUCTION`)의 태그 지시에 상위 개념(예: 녹차→음료, 치과→병원)을 포함하게 하고, 자동 추출(`EpisodeFactExtractor` / `KnowledgeAutoSaveFilter.tagsFor`)이 본문에 글자 그대로 있는 태그만 남기던 제약을 보강해 요약의 상위 개념 태그도 노트에 이어받거나, `add_memory` 태그 설명(`KosmosToolDeclarations.AddMemoryDeclaration`)에 상위 개념 예시를 더한다.
  모델 입력(요약 지시 또는 툴 선언)이 바뀌므로 PC 실험실 실측(`exp71_tag_enrichment.py` — 형식 준수·태그 상위 개념 포함률·M0 세트 전후 적중률·토큰 오버헤드·회귀 세트)을 먼저 돌리고 채택 범위를 확정한다.
- **M3 읽기 시점 질의 확장 (STOP)** — 검색마다 +1~2초(exp37: 11/16 → 13/16). M2 결과와 함께 사용자에게 비용 대 이득을 제시하고 진행 여부를 묻는다.
- **M4 마무리** — CHANGELOG · 계획서 상태 · 로드맵.
