## ① 약속 문장 제거 — 실측 완료 (exp43, 2026-10-01)
- 대상: 시스템 지시 "For EVERY user request, first decide if one of your tools applies. If it does, you MUST call the tool.
  Do NOT merely promise or pretend — promising without calling is a failure." (−39토큰, exp41 C2)
- exp41: 빼도 툴 선택 23/23. exp43: **호출 없이 했다고 말하기**를 직접 재는 조건 — 히스토리 없음 / 잡담 6왕복 뒤 / **모방 미끼**
  (앞선 비서 턴들이 툴 없이 "기억해 두었습니다·추가했습니다"라고 답한 히스토리) × 발화 8 = 24.
  기준선 **OK 24 · 약속 0** = 제거안 **OK 24 · 약속 0**. 게이트(제거안 ≤ 기준선) 통과.
- **한계(그대로 적는다)**: 기준선도 0 이라 이 조건들로는 문장이 막던 실패를 **재현하지 못했다** — "빼도 된다"가 아니라 "빼서 나빠지는 것을
  관측하지 못했다"이다. 같은 말을 매 턴 하는 턴 리마인더(exp20)가 실제 방어선으로 보인다. 실기기 게이트에 "툴 없이 했다고 말하기" 관찰을 둔다.
