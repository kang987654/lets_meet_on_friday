# Argon 인계 프롬프트 (0.41.13)

> 아래 구분선 사이를 그대로 붙여 넣는다. 한 세션에 끝나지 않으면 "이어서" 프롬프트를 쓴다.

---
이 저장소(KOSMOS, Android)의 0.41.13 회차를 구현해 줘. 계획은 이미 승인됐고, 너는 계획대로 실행만 하면 돼.

**먼저 읽을 것(이 순서로)**
1. `AGENTS.md` 전체 — 이 저장소의 정본 규칙이야. 계획서와 충돌하면 AGENTS.md 를 따른다.
2. `docs/plans/0.41.13-weekday-guard-and-repeat-refusal.md` — 이번 회차 계획서. "인계 메모", "근거 규칙", "금지", "멈춤 규칙"을 특히 지켜.
3. 계획서 "읽을 곳"의 파일들. 코드를 고치기 전에 실제 이름·줄을 직접 열어 확인해.

**일하는 방식**
- 마일스톤 순서대로(M0 → M1 → M2 → M3). 마일스톤마다 `./gradlew test lintDebug assembleDebug` 를 `-Pfast` 없이 돌려 녹색이면 master 에 한 줄 제목으로 커밋. 트레일러·본문 없음, 브랜치 만들지 않음.
- 커밋 전에 `git status` 로 staged 목록을 확인해. `gradle.properties`, `scratch/lab/regression/last_run_019_off.json`, `exp*_out*.txt` 는 절대 커밋하지 않아.
- 파일은 UTF-8(BOM 없음). 셸로 쓰지 말고 편집 도구로 써.

**근거 규칙 (가장 중요)**
- 지난번 인계에서 "확인했다"는 결론 중 틀린 것이 여러 번 나왔어. 그래서 이번에는 모든 주장에 `파일:줄` 이나 실제 실행한 명령의 출력 원문을 붙여. 근거 없는 주장은 쓰지 마.
- 실행하지 않은 것을 실행했다고 쓰지 마. 못 했으면 "못 함 — 이유"라고 적어.
- 수치는 이번에 직접 잰 것만. 옛 문서 수치를 쓰면 출처를 같이 적어.
- 모르면 추측하지 말고 "모름 — 확인 방법"으로 남겨.

**하지 말 것**
- 푸시, 회귀 세트 `--save-baseline`, 휴대폰·에뮬레이터 사용, 기존 테스트 단언 수정·삭제, `git reset --hard`·`git clean`, 계획에 없는 리팩터링·코드 삭제.
- 시스템 지시·툴 선언·리마인더 변경. M2 의 처방 적용.

**멈춤**
- 계획서의 "멈춤 규칙"에 걸리면 직접 고르지 말고, 계획서 맨 아래 "멈춤 질문"에 상황·선택지·근거를 적고 커밋한 뒤 끝내.

**끝낼 때**
- 계획서의 "구현 보고" 칸을 전부 채워(출력은 원문 그대로). 상태 줄은 "구현 완료 — Claude 검증 대기"로. 완료라고 쓰지 마.
- 마지막 답에는 마일스톤별 커밋 해시, 회귀 세트 점수 줄 원문, 계획과 갈린 곳, 멈춤 질문이 있으면 그 내용을 한국어로 짧게.
