# 0.38.5 — 말투

## 목표
화면 문구를 DESIGN Voice(해요체·짧게·결과 먼저·줄표 금지·세 항목 이상 가운뎃점 금지)와 한 낱말 체계로 맞추고,
모델 출력 말투(브리핑·주간 회고·채팅)는 **지시를 넣었을 때 실제로 얼마나 바뀌는지 먼저 재서** 효과가 있을 때만 넣는다.
0.38.2 에서 미룬 툴 표면 두 문제("몇 시야?" 재호출, 거절 뒤 "설정해 드렸어요")도 같은 실험실 세션에서 잰다.

## 정한 것 (2026-10-22 사용자)
1. **모델 말투 = 브리핑·회고 + 채팅** — 단, 기준값(지금 지시)과 후보를 같은 입력으로 재서 효과를 보고 정한다(사용자: "통제의 효과가 어느 정도일지는 봐야"). 채팅은 여유 50토큰 안 + 툴 스모크 무손상 + 거짓 성공 0 일 때만.
2. **답 속 이모지는 그대로 둔다** — 거르는 처리·금지 지시 없음. 실측 중 문제가 보이면 알린다.
3. **활동 기록은 화면에서만 가볍게** — 펼침의 ISO 시각 → 한국어 시각, 모델에게 하는 지시 문장("…알리세요"·"…물어보세요") 떼기. 툴 결과 원문(모델 입력)은 그대로, "원문 보기"도 그대로.
4. **미룬 두 문제 이번에 포함** — "몇 시야?"는 새 툴 대신 `get_schedule` 이 알림까지 돌려주는 안을 먼저 잰다(새 선언 비용 없음). 거절 회신은 문구 후보 실측.
5. **낱말 통일(추천 그대로)** — 지우기(목록에서만 빼는 최근 문서는 "빼기"), 다시 시도, 고르기, 내려받기, 알림(시스템 알림 채널 이름만 "정한 시각 알림"), 저장한 것은 메모·기능 영역은 기억("메모리"는 기기 RAM 에만).
6. 화면 문구의 "해 주세요" 띄어 쓴다(맞춤법).

## 지금 코드에서 확인한 사실 (2026-10-21 조사)
- 화면 문구: 느낌표·이모지 0, 합니다체 약 13(모델 관리·발열 경고·이미지 첨부·알림 채널 설명·위젯 설명·일정 빈 안내·복원 완료), 줄표 1(`ErrorMessages` 모델 손상), 세 항목 이상 가운뎃점 5(빈 채팅·첨부 안내·활동 기록 안내·설정 2), "해주세요"/"해 주세요" 혼재.
- 활동 기록 펼침에 툴 결과 message(합니다체·해요체·명사형 혼재)·ISO 시각·모델에게 하는 지시가 그대로(`AuditLabels`).
- 채팅 시스템 지시(`PromptAssembler`)에 말투 지시 없음. "활기찬 하루를 시작해 보세요!"는 코드에 없다 — 브리핑 지시 "밝은 인사 한 줄로 시작하세요"(`GenerateBriefingUseCase`)의 출력. 주간 회고 지시는 출력 말투를 정하지 않는다.
- 여유: `MEASURED_OVERHEAD` 1,250 + 프로필 100 ≤ 예약 1,400 → 50토큰. 브리핑·회고는 oneShot 이라 이 예산 밖. `PromptFixtureExportTest` 는 브리핑·회고 지시를 내보내지 않는다.
- 화면용 이모지 후처리 없음(TTS `SpeakableText` 만).
