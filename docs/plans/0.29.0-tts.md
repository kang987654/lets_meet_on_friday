# 내장 TTS 음성 출력 (0.29.0)

## Context

expand.md A2 — 음성 입력(전사)은 있는데 응답은 화면으로만 나온다. 손을 쓰기 어려운 상황(P6)의 나머지 반쪽.
사용자 결정(2026-10-01): 외부 TTS 가 아니라 **기기 내장 엔진(삼성·구글)**, 설정에 **자동 낭독 토글**.

**현황 (탐색 확정)**:
- TTS 코드 0줄. 매니페스트 `<queries>` 없음 — targetSdk 37 에서 **TTS 엔진 목록을 보려면 `TTS_SERVICE` 인텐트
  `<queries>` 선언이 필수**(패키지 가시성, API 30+). 빠뜨리면 `getEngines()` 가 비어 보인다.
- 응답 확정 지점: `ChatViewModel.handleAgentResult` 의 `AgentResult.Text`(스트리밍 완료 후 1회).
  녹음 시작: `ChatViewModel.toggleRecording`. 생성 취소: `cancelGeneration`.
- 설정 저장: `SettingsDataStore`(Preferences, 불리언 키 패턴 — `autoExtractEnabledFlow` 전례). 화면 `SettingsScreen`.
- `ChatViewModel` 은 E2E 3곳에서 수동 생성 — 생성자 인자 추가 시 생성부 수정(허용 범위).

## 사용자 확정 결정 (2026-10-01)
1. 내장 엔진(`TextToSpeech`) — 삼성(`com.samsung.SMT`)·구글(`com.google.android.tts`) 등 설치된 엔진 중 선택.
2. 설정에 자동 낭독 토글.

## 승인 결정 (2026-10-01 — 전부 제안대로)
- **D1 자동 낭독 기본값**: 꺼짐(확정 — 켜 두면 첫 실행부터 소리가 나 당황스럽다).
- **D2 자동 낭독 대상**: 모든 답변(확정) / 음성으로 물은 턴의 답변만.
- **D3 말풍선 재생 버튼**: 있음(확정 — 토글이 꺼져 있어도 원할 때 듣기). 재생 중엔 정지 버튼으로 바뀜.
- **D4 엔진 선택 UI**: "시스템 기본" + 설치된 엔진 목록(확정). 한국어 오프라인 음성이 없으면 엔진 설정 화면으로 안내.

## 고정 제약
- **오프라인(NFR1)**: 음성 선택 시 `Voice.isNetworkConnectionRequired == false` 이고 한국어인 음성만 쓴다. 없으면 낭독하지
  않고 설정에 안내(`ACTION_INSTALL_TTS_DATA`/엔진 설정). 네트워크 음성으로 몰래 넘어가지 않는다.
- 모델 무관 → 프롬프트 표면·예산 무변경. 백그라운드 낭독 없음(앱이 onStop 되면 정지).
- **녹음 시작 즉시 낭독 정지** — 안 그러면 마이크가 TTS 를 전사한다.
- E2E 계약 문자열(`"Attach"`/`"Send"`/`"Document Attached"`) 무변경. 새 버튼의 contentDescription 은 한국어.

## M1 — 플랫폼 래퍼
- `platform/speech/SpeechOutput.kt`(@Singleton, `open` — 테스트 대역용): `TextToSpeech` 지연 초기화(엔진 패키지 지정),
  `speak(messageId, text)`, `stop()`, `speakingMessageId: StateFlow<String?>`, `availableEngines()`,
  `koreanOfflineVoiceAvailable()`. 오디오 포커스(`AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`), `UtteranceProgressListener` 로 상태 갱신.
- 긴 텍스트는 `TextToSpeech.getMaxSpeechInputLength()` 이하로 문장 경계에서 분할해 `QUEUE_ADD`.
- 매니페스트 `<queries><intent><action android:name="android.intent.action.TTS_SERVICE"/></intent></queries>`.
- 테스트: Robolectric `ShadowTextToSpeech` — 분할 경계, stop 후 상태 null, 엔진 패키지 전달.

- 테스트(표 형식): 굵게·목록·코드 펜스·링크·빈 결과.

## M3 — 설정
- `SettingsDataStore`: `ttsAutoReadEnabled`(D1 기본값), `ttsEnginePackage`(빈 값 = 시스템 기본).
- `SettingsScreen`: "음성으로 읽어 주기" 토글, 엔진 선택, 한국어 오프라인 음성 없음 안내 행(탭 → 엔진 설정).
- 테스트: `SettingsViewModelTest` 토글·엔진 저장.

## M4 — 채팅 연동
- `ChatViewModel`: `AgentResult.Text` 확정 시 자동 낭독(D1·D2 조건), `toggleRecording`·`cancelGeneration`·새 메시지 전송·
  `onCleared` 에서 `stop()`. 앱 onStop 시 정지(`KosmosApp` 수명주기 관찰자에서 `stop()`).
- 말풍선 재생/정지 버튼(D3) — `ChatBubbles` 의 어시스턴트 말풍선, `speakingMessageId` 로 아이콘 전환.
- 테스트: 자동 낭독 켜짐/꺼짐, 녹음 시작 시 stop 호출, 에러 턴은 낭독 안 함(대역 `SpeechOutput`).
