# 문서 뷰어 1차 — 모델 없는 경량 뷰어 · PDF · xlsx · csv (0.34.0)

## Context

사용자가 xlsx 를 열 때 기기 문서 뷰어에 광고가 나와 불편했다(2026-10-02). 비서 앱이 어차피 문서를 다루므로
**앱 속 앱 형태의 문서 뷰어**를 넣는다. 사용자 중점: **모델을 켜지 않고, 최대한 가볍고 빠르게 열리는 것**.

전체 구성은 3회차다 — 0.34.0 뷰어 골격 + PDF·xlsx·csv, 0.35.0 docx·hwpx + 채팅 연결
(`0.35.0-document-chat.md`), 0.36.0 hwp 확인 실험(`0.36.0-hwp.md`).

**현황 (탐색 확정)**:
- **문서만 열어도 모델이 켜진다.** `KosmosApp.onCreate` 의 `ProcessLifecycleOwner` 옵저버가 **프로세스 전경 진입마다**
  `modelRunner.warmUp()` 을 건다(`KosmosApp.kt:69`). 화면과 무관하므로, 외부 "연결 프로그램"으로 뷰어를 열어도 3.6GB 로드가
  시작된다 — **이 회차의 선결 과제**.
- 화면 진입은 `MainActivity` 하나(singleTop, LAUNCHER + SEND 필터)이고 내비는 `AppDestination` + 스플래시(모델 대기)다.
- 드로어(`AppDrawerContent.kt:169~180`): "🧠 메모 · 할 일" 목록 줄 1개 + 타일 3개(캘린더·활동 기록·설정).
- 문서 관련 의존성 없음. APK 디버그 73MB.

## 사용자 확정 결정 (2026-10-02)
1. 지원 형식: **PDF · xlsx · csv**(이 회차). xls(옛 엑셀 바이너리)·doc 는 지원하지 않는다.
2. 진입점: **"연결 프로그램" 등록 + 앱 내 열기 둘 다**. 앱 내 진입은 **드로어 목록 줄 "📄 문서" → 문서 홈(최근 문서 + 파일 열기)**.
3. **보기 전용**: 편집·저장 없음. 차트·이미지·조건부 서식은 표시하지 않는다(xlsx).
4. 외부 라이브러리 없이 안드로이드 내장 기능만 사용(`PdfRenderer`, `ZipInputStream`, `XmlPullParser`).
5. 회차 분할: 뷰어·경량화 먼저, 채팅 연결은 0.35.0.

## 승인 결정 (2026-10-02 — 전부 제안대로)
- **D1 뷰어는 별도 Activity**(`DocumentViewerActivity`): 스플래시·NavHost·Room 을 거치지 않는다. 드로어에서 연 문서도 **같은 Activity**로
  띄운다(코드 경로 하나). 외부 진입은 채팅 태스크 위에 쌓이지 않도록 별도 태스크(`taskAffinity=""` + `documentLaunchMode="intoExisting"`)로 연다.
- **D2 모델 준비 트리거 이동**: `KosmosApp` 의 프로세스 `onStart → warmUp` 을 **`MainActivity` 의 `onStart`**로 옮긴다. 원래 [WHY]
  (빠른 재진입 시 스플래시가 낡은 Ready 를 보고 통과하는 구멍)는 "채팅 화면이 보일 때마다 멱등 warmUp" 으로 그대로 막힌다.
  **해제(`onStop → close()`)는 프로세스 단위로 유지**한다 — 앱 전체가 백그라운드일 때만 놓는다.
  - 결과: 외부에서 뷰어만 열면 모델 0 / 드로어에서 뷰어로 가면 이미 올라간 모델은 유지(채팅 복귀 즉시). 후자에서 메모리를 아끼려
    해제하면 복귀마다 재로드(수 초)가 붙어 기각.
- **D3 최근 문서**: 문서 홈에서 `ACTION_OPEN_DOCUMENT` 로 연 파일만 `takePersistableUriPermission` 후 DataStore 에 최근 20개(uri·이름·형식·
  열람 시각) 기록. 외부 "연결 프로그램" 진입은 임시 권한이라 재열람이 불가능하므로 **기록하지 않는다**(목록에 열리지 않는 항목을 남기지 않게).
  Room 이 아닌 DataStore — 뷰어가 DB 를 열지 않게.
- **D4 매니페스트 필터** (`DocumentViewerActivity`, `ACTION_VIEW` + `DEFAULT`/`BROWSABLE` 아님): `application/pdf`,
  `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, `text/csv`, `text/comma-separated-values`. 일부 파일 앱이
  `application/octet-stream` 으로 보내는 경우는 **필터에 넣지 않는다**(모든 바이너리에 뜨는 스팸 방지) — 실기기에서 누락이 확인되면
  확장자 판별 경로를 추가한다.

## 고정 제약
- **뷰어 경로에서 금지**: `ModelRunner` 주입·호출, Room DB 접근, 스플래시. 뷰어 ViewModel 은 문서 파서·DataStore 만 의존한다.
- 파싱은 전부 `Dispatchers.IO`, **첫 화면 우선**(스트리밍으로 첫 화면 분량이 차면 즉시 표시).
- 안전장치(상수, `core` 의 `Constants`): 압축 해제 총량 상한(예: 50MB), 단일 엔트리 상한, 시트 행 상한(예: 5만 행 — 넘으면 "앞 N행만"
  안내), PDF 페이지 비트맵은 화면 폭 기준 축소 + `LruCache`(메모리 1/8).
- 파서는 **순수 JVM 테스트 가능**하게 `InputStream` 입력으로 분리한다(Robolectric 불필요).
- 색은 `KosmosTheme.colors` 토큰만, UI 문자열 한국어. 채팅 프롬프트 무변경(`MEASURED_OVERHEAD` 무관). 기존 단언 수정 0건 목표.
- 테스트 픽스처 문서는 **테스트 코드가 생성**하거나 직접 만든 합성 파일만 커밋한다(개인 문서 금지).

## M0 — 모델 준비 트리거 이동 (선행, 단독 커밋)
- `KosmosApp`: 프로세스 옵저버의 `onStart` warmUp 제거(`onStop` 해제·`speechOutput.release`·`memoryCleanupRunner.cancel` 은 유지).
- `MainActivity`: `lifecycle` 의 `onStart` 에서 `modelRunner.warmUp()`(lifecycleScope). [WHY] 주석에 이동 이유(뷰어는 모델을 켜지 않는다) +
  원래 재진입 구멍 설명을 옮겨 적는다.
- 테스트: Robolectric — `DocumentViewerActivity` 가 생기기 전이므로, **다른 Activity 만 전경일 때 warmUp 이 불리지 않는다**를
  M3 에서 검증하고, M0 에서는 `MainActivity` 시작 시 warmUp 1회 호출(가짜 `ModelRunner` 바인딩)을 검증한다.
- 에뮬레이터: 콜드 스타트·백그라운드↔복귀 3회에서 스플래시 → Ready 정상(2026-08-14 재진입 결함 재발 없음).

## M1 — 문서 파서 (순수 JVM)
`app/src/main/java/com/kosmos/app/domain/document/`
- `DocumentType`(PDF·XLSX·CSV·UNSUPPORTED) + `detect(mimeType, fileName)` — MIME 우선, 없거나 octet-stream 이면 확장자.
- `SafeZip` — `ZipInputStream` 래퍼: 엔트리 이름 → 바이트, 압축 해제 총량·엔트리 상한 초과 시 실패 결과(예외 아님).
- `XlsxReader`:
  - `xl/workbook.xml`(시트 이름·순서, `date1904`) + `xl/_rels/workbook.xml.rels`(시트 파일 경로) + `xl/sharedStrings.xml` + `xl/styles.xml`
    (`numFmtId` → 날짜 서식 판별: 내장 14~22·45~47 + 사용자 서식의 y/m/d/h/s 토큰).
  - 시트: `<c r t s><v>/<is>` 를 `XmlPullParser` 로 스트리밍, 셀 타입 s(공유 문자열)·inlineStr·b·e·n·str. 수식은 **저장된 `<v>` 값만**.
  - 병합 셀 `<mergeCell ref>`, 틀 고정 `<pane xSplit ySplit state="frozen">`, 열 너비 `<col width>`(대략 환산).
  - 결과: `Sheet(name, rows: List<Row(index, cells: List<Cell(col, text)>)>, merges, frozenRows, frozenCols, colWidths, truncated)` — 희소 표현.
- `CsvReader` — RFC 4180(따옴표·이중 따옴표·셀 안 줄바꿈), 문자셋 UTF-8 → 실패 시 **CP949**(엑셀 한국어 저장 csv 대비) 판별, 행 상한.
- 테스트 `XlsxReaderTest`·`CsvReaderTest`: **테스트 안에서 `ZipOutputStream` 으로 최소 xlsx 를 조립**한다 — 공유 문자열·인라인 문자열·
  날짜 서식(1900/1904)·불리언·오류·수식 캐시 값·병합·틀 고정·빈 행 건너뜀·행 상한 절단·압축 해제 상한 초과·깨진 zip. csv: 따옴표 안
  쉼표/줄바꿈·CP949·빈 파일.

## M2 — 뷰어 화면 (xlsx·csv·PDF)
`app/src/main/java/com/kosmos/app/feature/document/`
- `DocumentViewerActivity`(`@AndroidEntryPoint`, `ComponentActivity`) — intent `data`(VIEW) 또는 extra 로 uri 수신, 테마는 `ThemeViewModel`
  그대로(KosmosTheme). 상단 바: 파일 이름 + 닫기, 시스템 바 인셋은 `TopAppBar` 내장 처리(§2-③).
- `DocumentViewerViewModel` — `load(uri)`: 형식 판별 → IO 파싱 → `Loading / Sheet(…) / Pdf(pageCount) / Error(사유)`.
  오류 문구: 지원하지 않는 형식 · 파일을 열 수 없음(권한) · 너무 큼 · 손상됨 · 암호 걸린 PDF.
- `SheetView` — 시트 탭(2개 이상일 때), `LazyColumn` 행 + 공유 가로 스크롤 상태, 틀 고정 행/열은 고정 영역, 열 머리(A, B, …)·행 번호,
  병합 셀은 첫 셀에 넓이 합산 표시(나머지 칸 비움). 셀 길게 누르면 값 복사.
- `PdfView` — `PdfRenderer`(ParcelFileDescriptor), `LazyColumn` 페이지 단위 렌더(보이는 페이지 ± 1), 화면 폭 축소 비트맵, `LruCache`,
  핀치 확대(`transformable`, 1~4배). `PdfRenderer` 는 단일 스레드 전용 — 전용 단일 스레드 디스패처로 직렬화(동시 `openPage` 크래시 방지).
  암호 PDF 는 `SecurityException` → 안내.
- 매니페스트: D1·D4 그대로.
- 테스트: `DocumentViewerViewModelTest`(형식별 상태 전이·오류 매핑, 파서 가짜 주입), Compose `SheetViewTest`(탭 전환·틀 고정 행이
  스크롤 후에도 보임·병합 셀 표시, ViewModel 수동 주입 — §2-②).

## M3 — 모델 미사용 검증 + 문서 홈 + 드로어
- `DocumentHomeScreen`(`AppDestination.Documents`, MainActivity NavHost 안): "파일 열기" 버튼(`OpenDocument` — MIME 배열은 D4 와 동일) +
  최근 문서 목록(아이콘·이름·열람 시각, 길게 눌러 목록에서 제거). 항목 탭 → `DocumentViewerActivity` 시작. 권한이 사라진 항목은
  "다시 선택해 주세요" 안내 후 목록에서 제거.
- `RecentDocumentsStore`(DataStore, D3) — JSON 한 키, 최신순 20개, 같은 uri 는 갱신.
- 드로어: "🧠 메모 · 할 일" 아래에 `DrawerListItem(icon = "📄", label = "문서")`. 타일 줄은 그대로.
- 테스트:
  - `DocumentViewerActivity` Robolectric: 가짜 `ModelRunner` 를 `@BindValue` 로 묶고 Activity 시작 → **warmUp 호출 0회**(D2 회귀 방지).
  - `RecentDocumentsStoreTest`(상한·중복 갱신·제거), `DocumentHomeScreenTest`(빈 상태 문구·항목 표시).

## M4 — 성능 측정 · 문서
- 에뮬레이터 측정(합성 파일: xlsx 1천·1만 행, PDF 50쪽): 앱 프로세스가 없는 상태에서 VIEW 인텐트(`adb shell am start -a VIEW -d … -t …`)
  → `ActivityTaskManager: Displayed` 시간과 첫 내용 표시까지, **logcat 에 엔진 초기화 로그가 없음**을 확인. 수치를 CHANGELOG 에 기록.
- `KosmosApp.onCreate` 의 eager 시작(briefing·episode)이 뷰어 콜드 스타트에 붙이는 시간이 크면(측정 > 200ms) 지연 시작을 별도 과제로 기록
  (이 회차에서 고치지 않는다 — 수명주기 계약 변경이라).
- CHANGELOG 0.34.0, `docs/architecture.md` 에 ADR(뷰어 분리 · 모델 준비 트리거 이동), `expand.md` 항목 추가, 이 계획서 상태 줄.

## 실기기 게이트 목록
- 삼성 "내 파일"·카카오톡 첨부·Gmail 첨부에서 xlsx/PDF/csv 의 "연결 프로그램"에 앱이 뜨고 열린다. octet-stream 으로 와서 누락되는 앱이 있는지.
- 외부에서 뷰어를 연 동안 모델이 로드되지 않는다(메모리·발열 체감, 개발자 옵션 실행 중 서비스 메모리).
- 뷰어에서 홈 → 채팅 앱 실행: 스플래시 → 정상 Ready. 뷰어 열린 채 채팅 앱 아이콘 → 태스크가 섞이지 않는다.
- 큰 xlsx(실사용 파일) 첫 화면 시간, 가로 스크롤·틀 고정 체감. PDF 확대 선명도.
- 라이트/다크 대비(셀 경계·머리글), 상태바·제스처 바 인셋.
