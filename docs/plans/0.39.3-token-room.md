# 0.39.3 — 고정 몫을 줄여 대화 기록 자리 늘리기 · 헤더 캡슐이 원인을 말하게

## 목표
1. 시스템 지시·툴 선언·턴 리마인더(고정 몫)를 실측으로 줄이고, 얻은 자리를 **대화 기록**에 준다 — 지금 기록 자리는 약 600~1,100토큰(2~4턴)이라 자동 정리가 잦다.
2. 헤더의 별이 노랑(발열)·빨강(엔진 오류)일 때 **원인이 화면에 보이게** — 캡슐 글자와 상태 시트.

## 정한 것 (2026-10-30 사용자)
1. 얻은 자리는 대화 기록에(새 툴을 넣을 때 다시 나눈다).
2. 컨텍스트 막대 · "지금 정리" 버튼은 **뺀다** — 0.39.2 부터 예산을 넘으면 답 직후 앱이 정리하므로 수동 버튼은 드물게만 쓸모 있다. 별 색은 엔진 상태 그대로(노랑·빨강을 대화 용량에 쓰면 발열·엔진 오류와 겹친다).
3. 화면: 캡슐 글자가 원인을 말한다 — 발열 경고면 "발열 주의 43°", 엔진 오류·모델 없음이면 "엔진 오류"/"모델 없음". 캡슐을 누르면 시트에 **원인 문장과 "다시 시도"**(설정의 다시 시도와 같은 경로).
   별을 누르는 설명은 두지 않는다(사용자: 불필요).
