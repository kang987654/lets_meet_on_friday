# 데이터 초기화 (0.37.1)

## Context
개발 중 쌓인 무의미한 대화·할 일·메모를 지울 방법이 없다(2026-10-14 사용자 요청). 개별 삭제(메모 ✕, 할 일 ✕, 기억 아카이브 삭제)는 있지만 대화 기록은 지울 수 없다.

## 승인 결정 (2026-10-14)
- **D1 범위**: 항목별 선택 — 대화 기록(채팅·브리핑 카드·기억 요약·감사 기록·호칭 제안) / 할 일(완료 포함, 알람 취소) / 메모 / 프로필(제안 카드 포함). 설정·모델·최근 문서는 유지.
- **D2 대화 기록을 지우면 앱 재시작** — 엔진 대화 KV·채팅 화면·에피소드 스케줄러가 메모리에 지운 대화를 들고 있다. 백업 복원과 같은 재시작 대화상자. 나머지 항목은 재시작 없이 반영.
- **D3 위치**: 설정 맨 아래 "데이터 초기화" → 체크박스 대화상자(되돌릴 수 없음·백업 안내, 고른 것이 없으면 버튼 꺼짐).

## 마일스톤
- **M1 데이터**: 도메인 `DataResetRepository`·`ResetTarget`, data `DataResetRepositoryImpl`(Room 트랜잭션 하나, 테이블 표), Robolectric 메모리 DB 테스트. 스키마 불변.
- **M2 화면·조율**: `DataResetViewModel`(알람 취소 → 삭제 → 위젯 갱신·세션 지움), 설정 섹션·대화상자, `restartApp` 공용화.
- **M3 문서**: CHANGELOG, 실기기 확인 목록.
