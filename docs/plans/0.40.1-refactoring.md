# 0.40.1 — UI 표준 문자열 리소스(`strings.xml`) 전환 · 큰 화면 구조 분리 · 코드/주석/문서 위생 정리

## 목표
`0.40.0` 에서 추가한 한/영 문자열 중 **화면(UI)·매퍼 4종·플랫폼 표면**이 실제로 안드로이드 표준 리소스(`res/values/strings.xml` · `res/values-en/strings.xml`)를 읽도록(`stringResource` / `context.getString`) 연결해 UI 층의 인라인 `if (en)` 분기와 `KosmosTheme.language` 를 걷어내고, 600~870줄로 비대해진 화면 파일 3종([ChatScreen.kt](../../app/src/main/java/com/kosmos/app/feature/chat/ChatScreen.kt), [SettingsScreen.kt](../../app/src/main/java/com/kosmos/app/feature/settings/SettingsScreen.kt), [MemoryScreen.kt](../../app/src/main/java/com/kosmos/app/feature/memory/MemoryScreen.kt))의 하위 컴포넌트를 분리하며, 낡은 주석·컴파일러 경고·미사용 리소스와 `0.40.0` 문서의 `configChanges` 오기를 바로잡는다.

| **2. 중복 코드 제거 (DRY) 및 한/영 분기 정리** | - **화면·매퍼 4종·플랫폼 표면의 `strings.xml` 정석 연결 (M1~M3)**:<br>  - 화면(`@Composable`)은 `stringResource(R.string.xxx)` 로, 화면 밖 플랫폼 표면(알림·위젯·타일·매퍼 4종 `ApprovalSheetContent`·`ResultCardMapper`·`AuditLabels`·`ChatChipRules`)은 `context.getString(R.string.xxx)` 로 통일한다.<br>  - **활동 재생성 경로 활용 (검토 3번 반영)**: 현재 매니페스트는 `configChanges="uiMode"` 뿐이라 언어를 바꾸면 Activity 가 재생성되며, `stringResource()` 는 그 자체로 새 언어의 `strings.xml` 을 읽는다. 따라서 `KosmosTheme` 에 별도 Context 로케일 래퍼를 두지 않고, M3 끝에 `KosmosTheme.language`(`LocalAppLanguage`)를 완전히 제거한다.<br>  - **Android 12 이하(API 26~32) 언어 토글 숨김 (검토 2번 ⓑ안 반영)**: `LocaleManager` 는 Android 13(API 33)+ 전용이므로, 리소스 기반 전환이 동작하지 않는 API 32 이하에서는 `SettingsScreen` 의 언어 토글을 숨긴다(`Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU`).<br>  - **인라인 문구를 정본으로 대조 (검토 4번 반영)**: 기존 `strings.xml` 331개 항목은 화면과 대조된 적이 없으므로, 교체할 때 **현재 코드에 적힌 인라인 한/영 문구를 정본**으로 삼아 `values/strings.xml` 과 `values-en/strings.xml` 의 문자열을 글자 단위로 맞춘다(스냅샷 변화 0건 보장).<br>- **모델이 읽는 문구 및 `:core`·`:domain` 순수 모듈은 현행 `AppLanguage` 분기 유지 (불변, 검토 1번 반영)**:<br>  - `:core` 순수 JVM 모듈의 [ErrorMessages.kt](../../core/src/main/java/com/kosmos/app/core/mapper/ErrorMessages.kt)(Android `Context`/`R` 없음, `AssistantMessageWriter`·`SendChatMessageUseCase` 가 대화에 비서 메시지로 저장해 다음 턴 모델 입력이 됨), 시스템 지시(`PromptAssembler`), 7개 툴 결과(`ToolExecutor`), 행동 가드 4종(`MemoSaveIntent`·`RepeatRequest`·`RefusalTurns`·`RecallConflict`·`ToolCallGuards`·`ReplyFinisher`·`BaseAgent`), 부수 추론(`SummarizeEpisodeUseCase`·`ExtractFactsUseCase`·`GenerateBriefingUseCase`·`GenerateWeeklyReviewUseCase`·`PlanMemoryMergeUseCase`·`EpisodeMerge`), 대화방에 비서 메시지로 저장되는 `ReminderEditor` 결과 문장, `:domain` 순수 유틸(`IsoDateTimeParser`·`KoreanHolidays`)은 코드의 `AppLanguage` 분기를 그대로 유지한다.<br>- **ViewModel 상태 내 문자열 (검토 6번 반영)**:<br>  - `ViewModel` 은 Activity 재생성에도 살아남으므로, `ChatViewModel`(`_episodeChipLabels`, `warningMessage`, 일회성 `suggestionNotice` 스낵바)이나 `ChatExtrasViewModel`(`_results` 카드 캐시)·`ProfileSheetViewModel`(`_error`) 등이 들고 있는 문자열은 언어를 바꾸는 순간 이미 떠 있던 카드/라벨이 다음 갱신 전까지 이전 언어로 남을 수 있다.<br>  - 이 중 화면에 상시 노출되는 `ChatViewModel._episodeChipLabels` 와 `ChatExtrasViewModel._results` 는 `appLanguageHolder.languageFlow` 가 바뀔 때 캐시를 비워(`invalidate`) 재생성된 화면이 새 언어로 다시 채우게 하고, 일회성 스낵바/편집 에러 문구는 발생 시점 언어 유지를 허용한다.<br>- **E2E 계약 문자열 보호 (AGENTS §2-②)**:<br>  - `"Attach"`·`"Send"`(`contentDescription`), `"Document Attached"` 는 테스트 계약이므로 리소스로 바꾸지 않는다. |
| **3. 아키텍처·레이어 경계 및 의존성 정리** | - `:core` 와 `:domain` 모듈은 Android `Context` 의존 없이 순수 JVM Kotlin 을 유지한다.<br>- 테스트 생성부를 건드리지 않도록 기존 클래스의 생성자 시그니처는 바꾸지 않고, 파일 내부의 미사용 private 심볼·불필요한 import 만 정리한다. |
| **4. 죽은 코드(Dead Code) 및 미사용 리소스 제거** | - M1~M3 에서 화면 문구를 `strings.xml` 에 모두 연결한 뒤, M4 에서 실제로 참조되지 않는 고아 `<string>` 항목(`UnusedResources`)과 호출자 0곳인 죽은 private 함수를 정리한다. |
| **5. 이름(Naming)·타입 안전성·불변성 개선** | - 컴파일러 경고(unused parameter, redundant qualifier 등)를 제거하고, `lintDebug` 의 `MissingTranslation` 0건을 유지한다. |
| **6. 주석·문서·테스트 코드 정리** | - **낡은 KDoc·주석 현행화 (M4, AGENTS §3)**:<br>  - [ChatScreen.kt:84](../../app/src/main/java/com/kosmos/app/feature/chat/ChatScreen.kt#L84) 의 `"Figma 스펙(Phase 2)에 맞춘 Glassmorphism 기반..."`(0.38.1 에서 폐기됨) 등 코드와 어긋난 주석을 `DESIGN.md`(v3) 기준으로 바로잡는다.<br>- **문서 정정 (M5)**:<br>  - [CHANGELOG.md](../../docs/CHANGELOG.md) `0.40.0` 및 [architecture.md](../../docs/architecture.md) ADR-033 에서 `MainActivity` 에 `configChanges="...|locale|layoutDirection"` 을 등록했다고 잘못 적힌 문장을 실제 동작(`configChanges="uiMode"` 유지 — 언어 변경 시 Activity 는 재생성되며 AI 엔진은 `KosmosApp` 프로세스 수명이라 내려가지 않음)으로 정정한다. |
