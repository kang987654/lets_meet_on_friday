# C2 MediaPipe 임베더 최소 제거 (0.26.0)

## Context

앱은 영어 전용 MediaPipe 텍스트 임베더(`universal_sentence_encoder.tflite`)를 싣고 있지만, 어떤 조회
경로도 임베딩을 읽지 않는다(ADR-013 — 한국어 분별력 0, 벡터 검색은 프로덕션 호출 0곳). 저장 시
`SaveKnowledgeUseCase` 가 `embed()` 를 부르지만 실패해도 저장은 성공한다. 0.25.0 에서 어휘 검색(바이그램
스코어러)이 회수 경로로 확정되어 C2 착수 조건(expand.md TD-1 "C1 품질 검증 후")이 충족됐다. 남은 몫은
**APK 약 28MB**(네이티브 lib 22.4MB + 자산 5.8MB, 2 ABI 기준 — CHANGELOG 0.16.x 실측), 기준선 release 77.8MB.

**현황 (탐색 확정)**:
- 의존 선언은 `data/build.gradle.kts:67-68` 한 곳(`implementation(libs.mediapipe.tasks.text)`), 카탈로그
  `gradle/libs.versions.toml:56-60`(version + [WHY]), `:137`(library). ProGuard·packaging·noCompress 설정 없음.
- 구현 `data/src/main/java/com/kosmos/app/data/embedder/MediaPipeTextEmbedder.kt`(108줄, 지연 초기화·JNI 예외
  방어) — 유일한 `TextEmbedder` 구현. 바인딩 `MemoryModule.kt:26-30`. 런타임 초기화·KosmosApp 참조 없음.
- 자산 `app/src/main/assets/models/universal_sentence_encoder.tflite` 6,120,274 B — assets 트리의 유일한 파일.
  루트 `download_model.ps1` 은 이 파일만 내려받는 스크립트. `scratch/lab/exp11_embedder.py` 는 이 자산 경로와
  `mediapipe.tasks` 를 import 하는 ADR-013 근거 실험.
- **테스트가 고정하는 계약(단언 불변)**: `TextEmbedder` 인터페이스·`SaveKnowledgeUseCase(repository, textEmbedder)`
  2인자 생성자(`MemoryPipelineIntegrationTest` 2건 — 임베딩 성공/실패 시 저장), `KnowledgeNote.embedding`·
  `knowledge_note.embedding BLOB`·`searchByVector`(`KnowledgeEmbeddingBlobTest` 6건), `FloatBytes`(`FloatBytesTest` 5건),
  `MIGRATION_4_5`(`KnowledgeEmbeddingMigrationTest` 7건). → **구현·의존·자산만 제거**, 계약 층은 유지.
- 문서 stale 수치: expand.md:90 "APK 52MB", :95 "152→~100MB", ENGINEERING_EVALUATION.md:102-103 "52MB"·"FTS5" —
  현행 기준은 −28MB, 77.8→~50MB(expand.md:210 TD-1).
- `assembleRelease` 는 서명 없이 `app-release-unsigned.apk` 를 낸다(minify·shrink 켜짐) — 바이트 비교에 충분.
  디스크의 8월 5일자 release APK(102.9MB)는 abiFilters 이전 산출물이라 기준선으로 쓸 수 없다 → 재빌드.

## 사용자 확정 결정 (2026-09-03)
1. **최소 제거** — MediaPipe 구현·gradle 의존·tflite 자산 제거 + 항상 실패를 돌리는 `DisabledTextEmbedder`
   바인딩. 인터페이스·컬럼·`searchByVector`·`FloatBytes`·테스트 25건 무변경(단언 수정 0건 규칙 유지, C3 되살림 자리).
2. **트리거 규칙(툴 미호출 2건)은 이번 회차에서 넘긴다** — 1건은 get_schedule 이 맞는 해석일 수 있고, 2건(과거
   대화 회상 트리거)은 23토큰 예산 안에서 완벽 해결이 어렵다. exp37 사실과 함께 CHANGELOG [Note] 에 후보로 기록.

## 고정 제약
- 기존 테스트 단언 수정 0건, 생성부 수정도 불필요(계약 층 유지). 게이트 `./gradlew test lintDebug assembleDebug`
  → 한 줄 커밋(60~70자, 세부는 CHANGELOG). 픽스처 날짜 드리프트는 `git checkout --`.
- 삭제보다 보관: `download_model.ps1`·`exp11_embedder.py` 는 `docs/archive/c2-mediapipe-2026-09/` 로 `git mv` + 사유
  README(ADR-013 근거 실험이라 이력 가치 있음). 자산 tflite 자체는 6MB 바이너리라 git 에서 삭제(이력에 남음).
- 프롬프트 표면·예산 무변경. `play-services-tflite`(LiteRT-LM GPU 델리게이트) 는 MediaPipe 가 아니다 — 건드리지 않는다.
- `scratch/lab/requirements-0.15.0.lock` 의 `mediapipe==1.0.0` 은 파이썬 실험실 환경 — 앱과 무관, 유지(exp11 보관 주석만).
