# 0.40.7 — 답 직후 입력과 대화 미리 준비 프리필의 GPU 경합 해소

## Context
답이 끝난 직후 입력란에 글을 치면 화면이 약 5초간 초당 2~3프레임으로 떨어진다(사용자 체감, 2026-11-03 실기기 SM-S938N).

**측정 (logcat, 디버그 빌드)**
- 느린 프레임 단계 분해: UI 스레드(입력~그리기) 1~9ms, **GPU 완료 대기 412~456ms** — 앱 코드가 아니라 GPU 를 프리필이 붙잡고 있다.
- 시점: 턴 종료 → 약 1.3초 뒤 `ConversationPrewarmer.afterTurn` 이 대화를 다시 만들고 프리필(5~7초) — 키보드가 올라오는 시점과 겹친다.
- 대화를 다시 만든 이유: 설정 예산이 **최소값 2,000**(기기 `max_tokens`)이라 재설정 임계값도 2,000. 오버헤드 약 1,400 을 빼면 히스토리 몫이
  약 600 이고, 턴 종료 KV 1,918·1,827·1,911 은 재사용, 2,021·2,179·2,261 은 재생성 — 툴 턴(위키 결과 250~400토큰)은 거의 항상 넘는다.
- 엔진·GPU 쪽 대안은 막혀 있다: AAR 0.18.0 의 `EngineConfig`·`Backend.GPU()`·`ExperimentalFlags`·JNI `nativeCreateEngine` 에 프리필 청크·GPU 우선순위
  항목이 없다(네이티브에는 `prefill_chunk_size`·`gpu_context_low_priority` 문자열이 있으나 노출 안 됨). Edge Gallery(0.18.1)도 같다. NPU 는 Gemma 4 칩별 파일이
  공개 목록에 없다.

**실험 (15초 지연 빌드, 커밋 안 함)**: 답 직후 타이핑 구간 느린 프레임 **0** (4회). 대가 — 지연 안에 보내면 그 턴이 재생성 프리필을 직접 치른다(툴 턴 뒤 17초),
준비가 엔진에 들어간 직후 보내면 끝날 때까지 기다린다(9.5초). 천천히 보내면 준비된 대화로 3.4초.

## 결정
- **D1 = 정책 유지**: 재설정 임계값 = 예산(ADR-029) 그대로. 기본 예산 `DEFAULT_CONTEXT_TOKENS`(2,500)는 이미 기본값이고, 기기 설정만 2,000 → 2,500 으로
  사용자가 옮긴다(히스토리 몫이 늘어 재생성 빈도가 준다). "예산 + 여유" 이력(hysteresis) 안은 예산 2,500 에서 효과가 없어 넣지 않는다.
- **D2 = 마지막 키 입력 5초**: 미리 준비는 턴 종료(또는 Ready)와 마지막 입력 활동 중 늦은 시각부터 **5초 조용하면** 시작한다. 기다리는 동안 입력이 있으면 다시 센다.
  엔진에 들어간 준비는 지금처럼 끝까지 간다(0.38.6 — 네이티브 추론 중 취소 금지).

### M1 — 입력 중에는 미리 준비를 미룬다 (D2)
- `Constants.PREWARM_QUIET_MS = 5_000`.
- `ConversationPrewarmer`
  - `onTyping(now)` — 마지막 입력 활동 시각 기록.
  - `afterTurn` 이 준비 전에 조용한 구간을 기다린다. 남은 시간 계산은 순수 함수(`now` 인자 — AGENTS §2-④)로 분리해 단위 테스트한다.
  - 기다림 길이는 테스트가 줄일 수 있게 `internal var quietMs`(Hilt 생성자에 Long 을 넣지 않는다). 기존 테스트 3건은 생성부에서 `quietMs = 0` 으로 —
    단언 불변(AGENTS §2-② 생성부 수정 허용).
  - Ready 편승 준비(`start`)도 같은 경로라 함께 5초를 기다린다 — 앱을 켜고 곧바로 묻는 첫 턴은 지금보다 늦을 수 있다(사용 안내 갱신).
- `ChatInputBar(onTyping: () -> Unit = {})` — 글자가 바뀔 때만 부른다(커서 이동 제외). 기본값은 E2E 계약(단독 compose).
- `ChatScreen` → `ChatViewModel.onTyping()` → `ConversationPrewarmer.onTyping()`. 녹음 시작도 입력 활동으로 본다.
  `ChatViewModel` 생성자에 `ConversationPrewarmer` 추가 — 테스트 생성부 5곳(+ScreenCatalog) 인자만 추가.
- 새 테스트: 남은 시간 순수 함수, "기다리는 동안 입력이 이어지면 준비하지 않고 조용해지면 준비한다".
- 모델 입력(지시·툴·결과 문구) 불변 → 실험실 실측·회귀 세트 대상 아님(AGENTS §2-⑤).
- 게이트 후 커밋.
