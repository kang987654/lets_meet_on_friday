# 0.38.8 — 앞 대화를 얼마나 믿을까

## 목표
0.38.7 실기기 확인에서 나온 모델 답 문제를 실험실에서 재현하고 고친다. 공통 원인은 "방금 대화"·"검색된 기억"·"자기 앞 답" 사이의 우선순위가
정해져 있지 않다는 것. 화면 쪽 남은 후보(은하 전환, 주제 섞인 요약 분리)도 함께.

## 정한 것 (2026-10-26 사용자)
1. **사실만 말할 때는 확인만, 저장은 물어본다** — "송장번호 6043 … 확인했어요. 메모해 둘까요?"처럼. 저장 툴 없이 "기억해 둘게요"라고 약속하지 않는다.
   사용자가 응하면 메모 저장(승인 시트). 저장 낱말("기억해", "저장해" 등)이 있으면 지금처럼 바로 저장.
2. **값이 다르면 방금 대화 > 메모 > 지난 대화** — 지금 대화에서 말한 값이 가장 최신이라 우선, 그다음 직접 저장한 메모(지금 규칙). (M2 뒤 수정: 옛 값 덧붙이기는 하지 않는다.)
3. **화면 쪽(은하 전환, 주제 섞인 요약 분리)도 이번 회차에.**

## 지금 알고 있는 것 (0.38.7 U 절, CHANGELOG 0.38.7 [Note])
- "택배 송장번호 …이야" → "그런 기능은 없어요"(실기기, 앞 비서 답이 엉뚱했던 기록). 새 대화 실험실에서는 거절 없이 "기억해 둘게요" 약속만(저장 호출 없음).
- 메모 거절 뒤 "회의실 어디라고 했지?" → 방금 말한 "5층 C룸" 대신 오전 지난 대화 요약의 "3층 B룸"(검색 결과 안내 HIT_TAIL 은 "목록에 답이 없으면"만 다룬다).
- 새 요약이 사용자 거절을 "저장하지 못했어요"(실패처럼)로 적는다 — 요약 입력에는 비서의 고정 문장 "메모에는 남기지 않았어요."만 있다.
- 은하가 열리는 동안 프레임 25~44ms(0.38.7 M3 뒤), 주제 둘 섞인 대화 요약 분리 6/8(exp59).
- 고정 예산 여유는 `TokenBudgetInvariantTest.MEASURED_OVERHEAD` 기준으로 계산(0.38.7 끝 51).

## 마일스톤 (각각: 측정 → 사용자 확인 → 구현 → 게이트 → 커밋)
- **M0 재현 세트** — 실기기에서 실패한 대화 모양을 실험실 세트로(엉뚱한 앞 답이 있는 기록, 메모 거절 뒤 되묻기, 옛 지난 대화가 검색되는 경우, 사실만 말하기).
  이후 마일스톤의 공통 기준(exp62).
  - **M0 결과(2026-10-26, 현행 기준값)**: A 거절 3/12(전부 앞에서 거절한 기록 뒤 — 엉뚱한 되물음 기록 뒤는 0) · 거짓 약속 1/12, B 거짓 약속 1/8 · 저장 호출 5/8 · 저장 물어봄 0/8,
    **C 방금 값 0/4 · 옛 값만 4/4**(실기기 재현), **D 실패처럼 0/4** — 실기기의 "저장하지 못했어요"는 0.38.6 빌드 거절 문장("메모를 저장하지 않았어요.") 때의 요약이라 지금 문장으로는 재현 안 됨 → M4 는 지켜보기로 줄인다.
- **M1 대화 기록에 끌린 거절** — 엉뚱한·거절하는 앞 답이 있을 때 따라 하는지 재현하고, 역할 줄·턴 리마인더 중 효과 있는 곳. exp58b 툴 밖 요청 세트·스모크 회귀.
  - **M1 결과(2026-10-26)**: 바꾸지 않음 — 세 후보 모두 현행보다 낫지 않다(exp62d). 남는 "송장번호" 거절은 M3 로(사용자 결정).
- **M2 새 값 vs 옛 값** — 결정 2를 검색 결과 안내(턴 몫)에 — 메모와 요약이 함께면 지금의 MIXED 안내 앞에 "이 대화에서 사용자가 방금 말한 값이 있으면 그것이 가장 최신".
  exp60 충돌 4/4·관련 결과 6/6 회귀.
  - **M2 결과(2026-10-26)**: 갈린 점 — 안내 문구(최고 2/4) 대신 결과 맨 위에 지금 대화의 사용자 말(4/4, 코드). "다른 값이 있었다고 덧붙이기"는 하지 않는다 — 새 값만으로 충분(사용자 결정, 결정 2 수정).
- **M3 사실을 말할 때** — 결정 1. 트리거 줄의 "shares a fact … to keep" 범위와 답 규칙(확인 + "메모해 둘까요?"). 거짓 약속 0, 명시 저장 6/6, 긍정 답 문장("응")으로 저장 이어짐.
- **M4 요약의 거절 표현** — 요약 입력의 거절 턴을 "(사용자가 승인하지 않음)"으로 표시하는 안 vs 요약 지시 한 줄. exp59 형식·보존·회수 회귀.
- **M5 화면 쪽** — 은하 전환: 열리는 동안 입자 수 줄이기·채팅 확대 끄기 비교(휴대폰 framestats, 온도 기록). 주제 섞인 대화 요약 분리(exp59 세트로 지시 후보).
- **M6 마무리** — CHANGELOG·계획서 상태, 휴대폰 확인(device_gate V) — 쓰시면서 볼 항목(위젯 13sp·라이트 엑셀·프로필 체크 목록)도 함께.
