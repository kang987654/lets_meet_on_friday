# 할 일 탭 관리 · 원문 대화 위치 (0.36.2)

## Context

2026-10-13 사용자 요청 세 가지.
1. 할 일 행 어디든 한 번 누르면 바로 완료된다(`TaskItemRow` 의 행 전체 `clickable`) — 되돌릴 방법도 없다.
2. "남은 일 n · 완료 m" 에서 완료 m 은 숫자뿐이다 — 목록은 미완료만 불러오고(`getPendingTasksData`) 완료 항목을 보거나 되살리거나
   지울 수 없다. 미완료 할 일도 지울 방법이 없다.
3. 기억 시트의 "원문 대화 보기"가 원문을 화면 **바닥**에 둔다 — 채팅 목록이 `reverseLayout` 이라 `scrollToItem` 이 대상 항목을
   시작 가장자리(바닥)에 놓는다.

## 승인 결정 (2026-10-13)
- **D1 완료 방식**: 체크 동그라미(터치 48dp)만 완료를 바꾼다. 행 본문 터치는 아무 일도 하지 않는다. 완료 직후 스낵바 "완료했어요 · 되돌리기".
- **D2 삭제**: 미완료·완료 항목 모두 ✕ + 확인 대화상자로 지운다(메모 카드와 같은 모양). 완료 묶음 끝에 "완료 항목 모두 지우기"(확인 후).
- **D3 완료 묶음**: 미완료 목록·추가 입력 아래에 접힌 "완료됨 m" 묶음. 펼치면 완료 시각 최신순 페이징 목록. 동그라미를 다시 누르면 되살린다.
- **D4 되살릴 때 리마인더**: 알림 시각이 미래·미발화면 다시 예약한다. 이미 지났으면 **발화하지 않고** 발화 처리(`markReminded`)해 둔다 —
  그대로 두면 재부팅 복원(`restoreAll`)이 지난 리마인더를 즉시 울린다.
- **D5 최근 기억**: 맨 위까지 올릴 수 없으면(대상 아래 대화가 한 화면 미만) 올릴 수 있는 만큼만 — 이때는 그 대화가 처음부터 끝까지 한 화면에 보인다.
  바닥에 임시 여백을 두는 안은 새 메시지·바닥 복귀 때 화면이 튀어서 기각.

## 마일스톤
- **M1 저장소**: `TaskDao` 완료 목록(`completedAt DESC`)·단건 삭제·완료 일괄 삭제, `TaskRepository` 동명 메서드. 스키마 불변(마이그레이션 없음).
- **M2 할 일 화면**: `MemoryViewModel` `completeTask`(되돌리기 정보)·`restoreTask`·`deleteTask`·`clearCompleted`, 완료 페이징 흐름.
  `MemoryScreen` 동그라미 전용 토글·✕·완료 묶음·스낵바 되돌리기. VM 단위 테스트(리마인더 재예약·지난 리마인더 미발화·삭제 시 알람 취소).
- **M3 원문 위치**: `ChatScreen.jumpToTimeline` — 이동 후 대상이 로드될 때까지(최대 1초) 기다렸다가 대상 윗변을 화면 윗변에 맞춘다.
  미로드 자리표시자로 정렬하면 내용이 채워지며 높이가 바뀌어 앞부분이 위로 잘린다.
- **M4 문서**: CHANGELOG 0.36.2, 실기기 확인 목록(원문 정렬·최근 기억·되돌리기)을 `docs/checklists/device_gate.md` 에.
