# 0.41.11 일정 툴 행동

> **상태**: 진행 중 (작성 2026-11-10, Claude 한 세션 — 사용자 승인: 일정 오인은 앱 가드 (가), 요약 항목 제외, 종료 시각 되묻기 추가)
> 정본 순서: **AGENTS.md > 이 계획서**. 충돌하면 AGENTS.md 를 따르고 충돌 사실을 사용자에게 알린다.
> 앞 회차: 0.41.10(앱 쪽 작은 결함). 휴대폰 확인은 0.41.10 몫과 함께 이 회차 끝에 한 번에(사용자 결정).
> 뒤 회차 후보: 반복 질문 일반 거절(0.41.3 관찰 — 원인 미상, 실험실 재현부터), 0.42.x Agentic 보강.

## 목표
1. **사실을 지금 시각 일정으로 만듦** — 앞 기록이 있을 때 "주차는 지하 2층 C-14에 했어"에 `add_schedule`(지금 시각 10:53~11:53)을 부른다
   (회귀 세트 fact h3, 0.41.9~). 앱에서는 승인 시트가 엉뚱하게 뜬다.
2. **시각을 말해도 다시 되묻고 추가하지 않음** — "회의 일정 추가해줘" → (모델이 물음) → "모레 오전 10시"에 "회의 제목과 종료 시간을 알려주시면…"으로
   또 묻는다(exp86). 선언에는 종료 시각 "모르면 시작 1시간 뒤", 시스템 지시에는 "선택 인자는 물을 이유가 아니다"가 있지만 nullable 인자도 required 로
   렌더링돼(KosmosToolDeclarations [WHY]) 모델이 필수로 보는 것으로 추정.

## 결정
- 목표 1은 앱 가드(사용자 결정 (가)): 이번 턴 사용자 말(과 그 앞 비서 말)에 날짜·시각 표현이 없으면 `add_schedule` 을 실행 전에 막고 안내를 돌려준다.
  exp86: "치과 예약 잡아줘"는 지금도 모델이 툴 없이 시각을 되묻고, "내일 3시"는 시각 표현이라 가드를 지나 추가된다 — 정상 경로는 그대로.
- 요약의 "요청했다"는 제외 — 0.41.9 exp85 로 요약 지시문 탓이 아님을 확인했다(답이 결과를 뺀 것, 재현 근거 1건).

## 고정 제약
- 모델 입력 변경은 이 회차의 처방만: 가드 안내 문구(툴 결과)와 M2 처방. 바꾸면 `engine.tokenize` 실측·회귀 세트·`MEASURED_OVERHEAD`(선언·지시가 바뀌면)·
  `kosmos_lab.py` 미러를 함께(AGENTS §2-⑤). 회귀 세트 흉내(`run.py`)에 가드를 같이 넣는다. 기준값 갱신은 결과를 보인 뒤.
- 기존 테스트 단언 불변. 한/영 같이(영어 가드 문구·시각 표현).
- 실험 스크립트는 새로 짠다(`scratch/lab/exp86~`), 출력은 커밋하지 않는다.

## 마일스톤

### M0 — 계획서·버전
- 이 계획서, `versionName = "0.41.11"`, `versionCode = 41011`.

### M1 — 일정 가드
- 도메인 순수 판정(`ScheduleTimeIntent` 같은 이름): 날짜·시각 표현 정규식(한/영). 사용자 말에 없고, 바로 앞 비서 말("내일 3시로 잡을까요?")에도 없으면 막는다 —
  앞 비서 말을 보는 이유는 "응"으로 확인하는 턴을 막지 않기 위해서.
- `ToolCallGuards` 에 한 줄, 안내 문구 한/영. 문구는 실험실에서 고른다 — exp86 의 첫 문구는 막기는 했지만 답이 "일정을 추가하려 했는데…"를 꺼냈다.
  기준: 주차·세차 같은 사실 문장에서 일정 이야기 없이 확인 + "메모해 둘까요?", 정상 일정 요청 문항 영향 없음.
- 테스트: 판정 단위 테스트, 가드 연결(BaseAgent 경로) 테스트. 회귀 세트 다시 실행.

### M2 — 종료 시각 되묻기
- 실험실 재현: 시각 없이 일정 부탁 → 모델 물음 → 시각만 답하는 2턴 문항 6~8개(회의·병원·저녁 약속·영어 포함). 지금 몇 건이 추가로 이어지는지.
- 처방 후보를 숫자로 고른다: ① 선언의 종료 시각·메모 설명을 "묻지 말 것"이 드러나게 ② 일정 트리거 규칙에 "제목은 사용자 말로, 종료는 1시간 뒤로 정하고 묻지 않는다"
  ③ 앱 쪽 보정(제목만 있으면 실행 등)은 모델이 툴을 안 부르니 해당 없음. 회귀 세트 새로 깨진 것 0 인 판만.
- 적용 시 토큰 실측과 `TokenBudgetInvariantTest.MEASURED_OVERHEAD`, `kosmos_lab.py` 미러, 픽스처 재생성.
- 처방이 지시문 큰 변경을 요구하거나 다른 행동이 흔들리면 멈추고 사용자에게 묻는다.
