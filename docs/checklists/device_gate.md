# 실기기 확인 체크리스트 (누적, 0.20 ~ 0.35)

> 작성 2026-10-07. 각 회차 CHANGELOG 의 "실기기 게이트(남음)"를 한 장으로 모았다 — **에뮬레이터에서 이미 통과한 항목은 뺐다**
> (0.26.1 에뮬레이터 통과 17건, 0.27.1 에뮬레이터 게이트 결과 참조). 괄호는 출처 회차·원래 번호.
> 실기기 DB 에는 실제 대화가 있으므로 **adb 자동화 없이 손으로** 확인한다(0.20.1 Note). 통과·실패는 다음 회차 CHANGELOG 에 옮긴다.

**준비**: 최신 debug 빌드 설치, 기기 캘린더에 종일 일정·여러 날 일정·공휴일 캘린더 구독, 시험용 파일(xlsx·csv·PDF(한글)·docx·hwpx),
메신저(카카오톡)·Gmail 로 시험 파일 하나씩 보내 두기, 음악 앱.
