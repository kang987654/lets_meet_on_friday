# 실사용 시작 체크리스트

> 개발 중 시험으로 쌓인 대화·메모·일정을 지우고 깨끗하게 시작할 때. **사용자가 직접** 한다(2026-11-19 확인, 0.42.10 점검).
> 매일 쓸 빌드는 디버그 빌드 그대로다(릴리스 전환은 포트폴리오·공개 때 — `docs/plans/0.43.0-real-use-prep.md` 보류).

## 앱이 지우는 것 — 설정 → 데이터 초기화
대상을 골라 한 번에 지운다(DB 의 모든 표가 어느 대상엔가 들어 있다).

| 대상 | 지워지는 것 |
|---|---|
| 대화 기록 | 대화·지난 대화 요약·활동 기록(새 체인으로 다시 시작)·프로필 제안, 지난 대화 뜻 검색 벡터 |
| 할 일 | 할 일·일정·알림 — **예약된 알림도 취소**되고 위젯 숫자도 갱신된다 |
| 메모 | 메모·주간 회고(회고도 메모로 저장됨), 메모 뜻 검색 벡터 |
| 프로필 | 프로필·프로필 제안 |
| 보관함 | 등록한 문서와 검색 색인 — 실제로 쓸 문서가 있으면 고르지 말 것 |

- 설정(테마·글꼴·언어·브리핑 시각 등)과 모델 파일은 지우지 않는다.
- 대화 기록을 지우면 앱 다시 시작 화면이 나온다.

## 앱 밖이라 직접 지울 것
1. **기기 캘린더의 시험 일정** — 일정 승인 시트에서 "추가하기"를 누른 것은 앱과 **기기 캘린더에 함께** 들어갔다. 캘린더 앱에서 지운다.
   휴대폰 확인 때 만든 제목 예: 아침 운동 · 헬스 · 치과 · 팀 미팅 · 미용실 · 점심 약속 · 회의(대부분 거절했지만 승인한 것이 있을 수 있다).
2. **앱 폴더의 디버그 파일**(있으면) — `Android/data/com.kosmos.app/files/` 의 `debug_embed.txt` · `debug_mtp.txt` · `diag_runaway.txt`.
   `models/`(채팅 모델)와 `embedding/`(뜻 검색 모델)은 **지우지 않는다**.

## 순서
1. (남기고 싶은 메모가 있으면) 메모 화면 메뉴 → 백업 내보내기.
2. 설정 → 데이터 초기화 → 대화 기록 · 할 일 · 메모 · 프로필 (보관함은 필요하면) → 앱 다시 시작.
3. 캘린더 앱에서 시험 일정 지우기.
4. 디버그 파일이 있으면 지우기(파일 앱 또는 `adb shell rm`).
5. 앱을 열어 채팅·메모·할 일·위젯이 비었는지 확인 → 실사용 시작.
