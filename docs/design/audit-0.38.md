## 발견 사항

### P1 — 출시 전 고칠 것

- **[P1] 하위 화면 돌아가기 수단이 화면마다 다르다** (사용자 ①) — 위치: 메모·할 일, 일정, 설정은 상단 바 없음. 문서·뷰어·기억 정리·활동 기록·모델 관리는
  `TopAppBar` 에 글자 버튼 "뒤로"(`TextButton`). 영향: 제스처 내비게이션 폰에서는 화면에 돌아가는 단서가 없다. 기준: Material — 하위 화면은 상단 앱 바 +
  내비게이션 아이콘(←). 권고: 모든 하위 화면에 같은 `TopAppBar`(← 아이콘 + 제목), 시스템 뒤로는 지금처럼(`navigateBack` 루트 가드 유지). → 0.38.1
- **[P1] 승인 UI 가 두 종류** (사용자 ②) — 위치: 일정 = 채팅 안 떠 있는 카드(`CalendarDraftCard`, [거절][승인하고 저장]), 리마인더·메모 = 바텀시트
  (`ApprovalSheet`, [취소][승인]). 영향: 같은 결정인데 위치·모양·문구가 달라 학습이 안 된다. 권고: 모두 바텀시트 하나(D6 ①), 문구 통일. E2E 셀렉터
  ("거절"/"승인하고 저장")는 테스트와 함께 정리. → 0.38.2 M4
- **[P1] 글자로 쓰인 강조색·보조색 대비 미달** — 위 표. 영향: 링크형 버튼·설명 글·다크 보조 글자가 읽히지 않는다(다크 `textMuted` 2.4:1 은 사실상 안 보임).
  권고: DESIGN.md v3 에서 **글자용 단계를 따로**(하늘색 계열 짙은 단계 ≥4.5:1, 다크 보조 글자 ≥4.5:1), 버튼 위 글자는 짙은 글자 또는 짙은 버튼. → 0.38.0 M2·M3, 0.38.1 M1
- **[P1] 이모지·글자 기호를 아이콘으로** — 12개 파일 39곳 이모지 + 글자 기호 버튼 6곳(✕ › ▾ ▴ +). 영향: 기기마다 모양·굵기가 다르고, 설정 섹션처럼 같은 ⚙ 가
  반복돼 아이콘이 정보를 주지 못한다. 기준: Material Symbols 한 세트. 권고: D4(Material Symbols Rounded) 로 일괄. → 0.38.1 M4
- **[P1] 시스템 바가 항상 검다** — 매니페스트 옛 테마(`Theme.NoTitleBar`). 영향: 라이트 화면 위아래에 검은 띠, 앱이 칠할 수 없다(0.36.1). 권고: edge-to-edge +
  화면별 인셋. → 0.38.1 M2 (실기기 확인)

### P2 — 다음 단계에서

- **[P2] 글자 버튼에 역할이 없다** — `Text(...).clickable` 10곳 이상(✕ 삭제, "추가", 설정 "정확한 알림 허용하기" 등). 영향: TalkBack 이 버튼으로 읽지 않는다.
  권고: `IconButton`/`TextButton` 또는 `Modifier.clickable(role = Role.Button)` + 설명. → 0.38.1 M4 와 함께
- **[P2] ✕ 삭제 터치 영역이 작다** — 메모 카드 ✕ 는 글자 + 좌우 여백뿐(약 24dp 안팎). 기준: 48×48dp. 권고: `IconButton`(48dp). → 0.38.1 M4
- **[P2] 자체 분할 버튼** — `GlassSegmentedControl` 4곳(메모/할 일 탭, 일정 월/목록, 테마, 응답 스타일). 기준: M3 `SingleChoiceSegmentedButtonRow`. 권고: M3 컴포넌트를
  우리 토큰으로 테마. → 0.38.1 M5
- **[P2] 모든 것이 같은 무게의 둥근 테두리 카드** — 설정 섹션·메모·드로어·카드가 전부 같은 유리 카드. 영향: 무엇이 중요한지 위계가 없다(craft-floor "카드는 게으른
  그릇"). 권고: 목록은 카드 대신 행 + 구분선, 카드는 결과(일정·알림·기억)에만. → 0.38.1 M5, 0.38.2
- **[P2] 제목 위 작은 회색 라벨** — "기억 아카이브", "백업", "최근 문서", 설정 섹션 머리("로컬 AI 모델 (GEMMA)") 등. craft-floor 가 금지하는 제목 위 라벨(eyebrow) 패턴에
  가깝고, 다크에서 `textMuted` 라 거의 안 보인다. 권고: 섹션 제목을 제대로 된 단계(Title)로, 필요 없으면 삭제. → 0.38.1 M3
- **[P2] 그라데이션 사용자 말풍선·발광 구슬·오로라** — craft-floor "장식용 유리·그라데이션". D5 대로 제거, 개성은 한 곳. → 0.38.1 M5
- **[P2] 태블릿·가로 대응 없음** — 창 크기 클래스 미사용. 휴대폰 개인 앱이라 우선순위 낮음. 권고: 최소한 가로에서 잘림 없는지 실기기 확인.

### P3 — 여유가 있으면

- **[P3] 무한 애니메이션 3곳** — `AuroraBackground`(스플래시), `OrbPulse`(헤더·스플래시), `ThinkingDots`. 시스템 "애니메이션 제거" 설정에서의 동작 실기기 확인,
  헤더 구슬은 상태 표시라면 정지 상태로 충분한지 검토(발열에 민감한 앱). → 0.38.3
- **[P3] 스플래시가 의도(항성·행성)와 다르다** (사용자 ④) — 빛나는 구슬 하나. D5 "개성 한 곳" 후보로 브랜드 마크(항성 + 궤도) 재디자인. → 0.38.3
- **[P3] 활동 기록 원문 노출** — 이벤트 이름 `SEARCH_USED`·`APPROVAL_GRANTED`, `Session: s-catalo…` 가 그대로. 권고: 사람 말 라벨. → 0.38.4(문구)

## 반복되는 문제 (체계적 원인)

- **글자색 단계가 하나뿐** — `accent`·`danger`·`textMuted` 가 면 색과 글자 색을 겸한다 → 대비 미달이 화면마다 반복. 토큰에 "글자용" 단계를 분리하면 한 번에 풀린다.
- **컴포넌트 대신 손으로 만든 요소** — 글자 "뒤로", 글자 ✕, 자체 분할 버튼, 유리 카드. Material 3 컴포넌트를 우리 토큰으로 테마하는 쪽으로 옮기면 접근성·적합성이 같이 오른다.
- **장식이 위계를 대신함** — 유리·그라데이션·테두리가 모든 요소에 같은 무게로 붙어, 정작 결과(일정·알림·기억)가 돋보이지 않는다(D1 "화면은 조용하게"와 반대).

## 잘 된 점

- **토큰 규칙이 살아 있다** — 테마 밖 하드코딩 색 0(§4-6), 팔레트 교체가 파일 하나로 끝난다.
- **글자 크기는 sp** — 시스템 글꼴 크기를 따른다(직접 크기 45곳은 단계로 옮기면 된다).
- **안드로이드 상호작용 문법은 맞다** — 바텀시트·스낵바·예측 뒤로·루트 가드(`navigateBack`)·키보드 처리(adjustResize).
- **목록 성능** — LazyColumn + 페이징, 원문 이동 정렬(0.36.2)까지 다듬어져 있다.
- **E2E 계약·상태 처리** — 빈 목록·완료됨·되돌리기 등 상태가 대부분 있다.
