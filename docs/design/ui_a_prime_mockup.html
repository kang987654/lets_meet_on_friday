시안 A에서 바뀐 것

세션 목록 → 기억 아카이브. 드로어의 목록은 사용자가 만든 세션이 아니라 시스템이 자동 분절·요약한 에피소드 문서다. 관리 대상이 아니라 열람 대상 — 단, 삭제·수정은 가능(P4 통제권).
"새 대화" 버튼 삭제. 경계는 시간 간격+리셋이 자동으로 만든다(exp33 ①). 사용자는 리셋을 의식할 필요가 없다 — 자비스에게 "새 세션"이라고 말하지 않는 것처럼.
회수 칩(🧠)이 신뢰 장치. 과거를 참조한 답변에는 어느 에피소드에서 왔는지 표시. 칩을 탭하면 A′-3 시트. 위키 뱃지(🌐)와 같은 문법 — 검색 미스가 "까먹음"으로 느껴지는 실패 모드의 완화책.
브리핑이 대화로 도착. 시안 B의 허브를 별도 탭이 아니라 아침마다 타임라인에 도착하는 비서 카드로 흡수. "비서 본체는 대화" 원칙과 허브 아이디어의 합집합.

동작 규칙

  • 타임라인: 무한 스크롤로 과거 열람(날짜 구분선 기존 것 재사용). 살아있는 KV 는 현재 에피소드 꼬리뿐 — 과거는 화면에는 보이되 모델 문맥에는 없고, 필요하면 SearchMemory 가 회수
  • 분절: 30분 무활동 또는 예산 리셋 → 에피소드 닫힘 → oneShot 요약(제목/태그/요약) → 아카이브 저장. 실패해도 원문은 남으므로 데이터 손실 없음
  • 검색: 드로어 검색바와 SearchMemory 툴이 같은 색인(FTS5 + 모델 검색어 확장)을 씀
  • 프로필(C′): 드로어 최상단 고정 카드 — 항상 주입되는 소량 기억. 탭하면 편집
  • 캘린더·활동기록·설정: 드로어 하단 타일 (시안 A와 동일)
