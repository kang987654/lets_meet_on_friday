이유 1 — 확장 로드맵과의 정합. expand.md Phase 1~2의 주인공(A1 세션 관리, A4 아침 브리핑, B1 리마인더)이 전부 자연스러운 집을 갖는 유일한 구조입니다. A는 브리핑이 어색하고, C는 리마인더가 들어올 때 재논의가 필요합니다.

2단계 제안 — 1단계: 탭 재편 + 채팅 헤더/입력바 재설계 + 대화 목록 화면(오늘 탭은 일정 카드만으로 시작). 2단계: 브리핑·리마인더가 구현될 때 오늘 탭에 카드 추가. 이러면 "반쯤 빈 홈" 문제를 피하면서 B의 골격을 미리 확보합니다.
